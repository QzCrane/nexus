# Nexus Kernel

跨平台核心: 消息路由 + 存储抽象

## 模块

- messages/router.ts: 路由分发
- messages/sender.ts: 发送封装
- storage/: 存储层

## 存储

文件: 数据
global-settings.ts: GlobalSettings
audio-config.ts: AudioConfig (按域名)
hotkey-settings.ts: Slots + Sites
site-registry.ts: DomainEntry

## API

`getHotkeySettings()` / `setHotkeySettings()` / `resetHotkeySettings()`

## 依赖

@nexus/contracts + chrome.storage.local
