# Nexus Kernel

**用途**: 跨平台核心逻辑 (消息路由 + 存储)。

## 模块

- messages/router.ts: 消息路由分发
- messages/sender.ts: 消息发送封装
- storage/: 存储模块

## 存储模块

- global-settings.ts: GlobalSettings
- audio-config.ts: AudioConfig (按域名)
- hotkey-settings.ts: HotkeySettings (Slots + Sites)
- site-registry.ts: DomainEntry 注册表

## 快捷键存储

```typescript
getHotkeySettings(): { slots, sites }
setHotkeySettings(partial)
resetHotkeySettings()
```

## 依赖

- @nexus/contracts (类型)
- chrome.storage.local
