# Nexus Kernel 上下文

**核心职责**: 消息通信 (RPC) + 存储封装 + 统一日志。

## 公共 API

- `createMessenger/Router`: 跨端 RPC。
- `StorageRepository`: 统一存储访问 (chrome.storage)。
- `createLogger`: 带有 `[SPECTRA]` 标记的标准颜色日志。

## 约束

- 消息必须预先在 `@nexus/contracts` 定义。
- 每个 Context (Popup, Content, SW) 仅允许一个 Messenger/Router 实例。
- 所有下游模块必须复用此处的日志模块。
