# NEXUS Kernel

**用途**：消息通信 (RPC Bus) + 存储访问

## 公共 API

```typescript
import { createMessenger } from "@nexus/kernel"; // Popup/Content
import { createRouter } from "@nexus/kernel"; // Background
import { StorageRepository } from "@nexus/kernel"; // Storage
```

契约：`@nexus/contracts/messages.contracts.ts`

## 存储

```typescript
storage.registry.query(domain)    // 查询域名状态
storage.registry.markProbed(...)  // 标记已检测
storage.registry.add/remove(...)  // 增删
```

## 约束

- 消息类型必须先在 contracts 中定义
- 每个上下文只创建一个 Messenger/Router
