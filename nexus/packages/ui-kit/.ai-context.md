# UI-Kit 上下文

## 身份

共享 UI 组件库 | Spectra/Halo 公用

## 导出

### 工具函数

- `$`/`$required`/`$$`: DOM 选择器
- `getDomain`/`isRestrictedUrl`: URL 工具

### 主题

- `applyTheme`/`getNextThemeMode`: 主题管理
- `THEME_ICONS`: 主题图标 Map

### 组件

- `Toggle`: 开关组件 (sm/md/lg)
- `Card`: 卡片容器 (default/outlined/elevated)

## 依赖

@nexus/contracts (ThemeMode) | React 18 (peer)
