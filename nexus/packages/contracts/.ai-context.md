# Contracts

**用途**：纯类型层，所有公共接口的唯一定义源

## 文件说明

| 文件                    | 用途                                |
| ----------------------- | ----------------------------------- |
| `audio.contracts.ts`    | 音频配置、策略上下文、服务接口      |
| `messages.contracts.ts` | RPC 消息定义、Messenger 接口        |
| `settings.contracts.ts` | 全局设置、存储仓库接口              |
| `common.types.ts`       | 通用工具类型 (Result, Maybe, TabId) |

## 约束

- **零依赖**：不允许任何 `dependencies`
- **纯类型**：只含 `interface`/`type`/`const`
- **AI 首读**：修改任何模块前应先读此包
