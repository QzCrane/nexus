# Contracts 包

**用途**: 纯类型定义，零运行时依赖。

## 核心契约

- audio.contracts.ts: AudioConfig, AudioMode, IAudioService
- messages.contracts.ts: NexusMessages, INexusRouter
- settings.contracts.ts: GlobalSettings, IStorageRepository
- registry.contracts.ts: DomainEntry, RegistryStorage
- hotkeys.contracts.ts: 快捷键类型 + 配置
- actions.ts: 消息 Action 常量

## 快捷键契约

```typescript
HotkeySettings: {
  slots: SlotMapping;      // Chrome Command → Action
  sites: Record<string, SiteHotkeyConfig>;
}

SiteHotkeyConfig: {
  enabled: boolean;        // 默认 false
  bindings: HotkeyBinding[];
}
```

## 导出常量

- DEFAULT_AUDIO_CONFIG
- DEFAULT_HOTKEY_SETTINGS, DEFAULT_SLOTS
- HOTKEY_ACTIONS (70+ 动作)
- Actions, OffscreenActions
