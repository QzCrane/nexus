# Audio Engine

WebAudio 节点链 + 模式决策 + CORS 探测

## 节点链

Source → Gain → Bass → EQ[10] → Comp → Panner → Delay → Analyser → Dest

## API

- needsAdvancedProcessing(): 需增强?
- predictCapture(): 预判劫持
- WebAudioController: 节点生命周期

## 决策矩阵

| 需求 | 受限 | 模式            |
| :--: | :--: | --------------- |
|  ❌  |  -   | NATIVE_LITE     |
|  ✅  |  ❌  | NATIVE_WEBAUDIO |
|  ✅  |  ✅  | CAPTURE         |

## 约束

- CORS: 6s 观察 Analyser (非零=安全)
- enabled=false 时禁止预判
