# Audio Engine

**用途**: WebAudio 节点链 + 模式决策 + CORS 探测。

## 节点链

Source → Gain → Bass → EQ[10] → Comp → Panner → Delay → Analyser → Dest

## 核心 API

- needsAdvancedProcessing(): 判定是否需增强模式
- predictCapture(): 基于域名+配置预判劫持
- WebAudioController: 节点生命周期管理

## 决策矩阵

| 需求 | 受限 | 模式            |
| :--: | :--: | :-------------- |
|  ❌  | 任意 | NATIVE_LITE     |
|  ✅  |  ❌  | NATIVE_WEBAUDIO |
|  ✅  |  ✅  | CAPTURE         |

## 约束

- CORS 探测: 6s 观察 Analyser 数据 (非零=安全)
- 预判须感知 enabled 状态，插件关闭时禁止预判
