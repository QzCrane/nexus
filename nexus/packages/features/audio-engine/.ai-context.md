# Audio Engine

**用途**：WebAudio 音频图 + 策略判断 + 颜色预判

## 公共 API

```typescript
import {
  PolicyEngine,
  WebAudioController,
  predictCapture,
  UIColors,
} from "@nexus/audio-engine";
```

## 策略 v3.0 (行为检测)

| 高级需求 | 受限站点 | 模式            |
| -------- | -------- | --------------- |
| ❌       | 任意     | NATIVE_LITE     |
| ✅       | ❌       | NATIVE_WEBAUDIO |
| ✅       | ✅       | CAPTURE         |

**高级需求** = 音量>100% || 频谱 || EQ || 压缩器 || 低音

## ❌ 禁止

- 添加 URL 路径规则
- 重复定义常量 / 硬编码 Action
