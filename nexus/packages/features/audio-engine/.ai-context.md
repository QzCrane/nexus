# Audio Engine

**用途**：WebAudio 音频图 + 策略判断 + CORS 检测

## 音频图节点链

`Source → Gain → Bass → EQ[10] → Comp → Panner → Delay → Analyser → Dest`

| 节点   | 功能        | 控制参数        |
| ------ | ----------- | --------------- |
| Gain   | 音量/单声道 | volume, mono    |
| Bass   | 低音增强    | bass            |
| EQ[10] | 10 段均衡器 | eqValues[]      |
| Comp   | 动态压缩    | compressor      |
| Panner | 声道平衡    | pan (-1~1)      |
| Delay  | 声画同步    | delay (0~500ms) |

## 策略 v3.0

| 高级需求 | 受限站点 | 模式            |
| -------- | -------- | --------------- |
| ❌       | 任意     | NATIVE_LITE     |
| ✅       | ❌       | NATIVE_WEBAUDIO |
| ✅       | ✅       | CAPTURE         |

**高级需求** = volume>100 || EQ || compressor || bass || pan!=0 || delay!=0

## CORS 检测

- `setSkipCorsCheck(true)` 缓存命中时跳过重复检测
- 检测流程：AnalyserNode 数据观察 6s，有数据=SAFE
