# Audio Engine

**用途**：WebAudio 音频图 + 策略判断 + CORS 检测

## 公共 API

```typescript
import {
  PolicyEngine,
  WebAudioController,
  predictCapture,
  UIColors,
} from "@nexus/audio-engine";
```

## CORS 检测 (v3.11)

- 延迟 500ms 启动观察模式
- 每 500ms 检测一次，持续 6 秒
- 有数据 → SAFE，超时无数据 → RESTRICTED
- 暂停/静音时等待 play 事件
- SAFE 可覆盖 RESTRICTED 误判

## 策略 v3.0 (行为检测)

| 高级需求 | 受限站点 | 模式            |
| -------- | -------- | --------------- |
| ❌       | 任意     | NATIVE_LITE     |
| ✅       | ❌       | NATIVE_WEBAUDIO |
| ✅       | ✅       | CAPTURE         |

**高级需求** = 音量>100% || 频谱 || EQ || 压缩器 || 低音

## 约束

- 日志使用 `@nexus/kernel` 的 `corsLogger`（遵循依赖方向）
- 不添加 URL 路径规则，仅用 CORS 检测
