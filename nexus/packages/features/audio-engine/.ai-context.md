# Audio Engine

**用途**：WebAudio 音频图管理 + 网站策略判断 + 颜色预判

## 公共 API

```typescript
import {
  PolicyEngine,
  WebAudioController,
  predictCapture,
} from "@nexus/audio-engine";

// 颜色预判 (统一判断 CAPTURE 紫色)
const isCapture = predictCapture({ config, isRestricted, visualizerEnabled });
```

契约：`@nexus/contracts/audio.contracts.ts`

## 策略决策 (v3.0)

| 高级需求 | 受限站点 | 模式            |
| -------- | -------- | --------------- |
| ❌       | 任意     | NATIVE_LITE     |
| ✅       | ❌       | NATIVE_WEBAUDIO |
| ✅       | ✅       | CAPTURE         |

## 约束

- AudioContext：每个标签页一个，需 resume()
- CORS：跨域需回退 Tab Capture
- 颜色判断：**必须使用 predictCapture**，禁止重复逻辑
