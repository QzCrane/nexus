# Audio Engine 上下文

**核心职责**：WebAudio 节点链 + 模式决策 + CORS 探测

## 音频工程

- **节点链**: `Source → Gain → Bass → EQ[10] → Comp → Panner → Delay → Analyser → Dest`
- **核心逻辑**:
  - `needsAdvancedProcessing`: 判定静默/增强模式的分水岭。
  - `predictCapture`: 基于域名与配置预判劫持。
  - `WebAudioController`: 节点生命周期与 Analyser 采集。

## 决策策略 v3.0

| 场景 | 需求 | 受限 | 模式                |
| :--- | :--: | :--: | :------------------ |
| 默认 |  ❌  | 任意 | **NATIVE_LITE**     |
| 安全 |  ✅  |  ❌  | **NATIVE_WEBAUDIO** |
| 受限 |  ✅  |  ✅  | **CAPTURE**         |

## 实现要点

- **CORS 探测**: 观察模式 (6s)，通过 Analyser 频谱数据（非零即安全）判定并缓存结果。
- **预判规则**: 必须感知 `enabled` 状态，严禁插件关闭时预判劫持。
