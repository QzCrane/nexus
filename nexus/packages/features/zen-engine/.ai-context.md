# Zen-Engine 上下文

## 身份

HALO 功能引擎 | 效能/美学特性

## 导出

### 深色模式

- `enableDarkMode(config?)`: 启用 SVG 矩阵反转
- `disableDarkMode()`: 移除样式和滤镜
- `toggleDarkMode()`: 切换状态
- `isDarkModeEnabled()`: 查询状态

### 平滑滚动

- `enableSmoothScroll(root?, product?)`: 启用惯性滚动
- `disableSmoothScroll()`: 禁用
- `isSmoothScrollEnabled()`: 查询状态

## 技术

深色: SVG feColorMatrix + CSS filter (无 DOM 遍历)
滚动: requestAnimationFrame + ease-out-quart

## 依赖

@nexus/kernel (Logger) | @nexus/contracts
