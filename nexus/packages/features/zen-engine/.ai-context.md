## 深色模式 (dark-mode.ts)

### 性能目标

- **激活时间**: <50ms (Dark Reader: 500-2000ms)
- **CPU 占用**: 零 JS 轮询
- **白闪防护**: document_start + color-scheme meta

### 技术实现

```
HTML filter: invert(1) hue-rotate(180deg) brightness(0.9)
媒体保护: 双重反转 (img/video/canvas/iframe/svg)
滚动条: 深色自定义
选择: 蓝色高亮
```

### API

```typescript
enableDarkMode(config?: DarkModeConfig)
disableDarkMode()
isDarkModeEnabled(): boolean
toggleDarkMode(): boolean
DARK_MODE_PRESETS: { default, highContrast, warm, pure }
```

### 配置

| 参数             | 类型     | 默认  | 说明       |
| ---------------- | -------- | ----- | ---------- |
| brightness       | number   | 0.9   | 亮度       |
| contrast         | number   | 1.05  | 对比度     |
| grayscale        | number   | 0     | 灰度       |
| sepia            | number   | 0     | 暖色调     |
| excludeSelectors | string[] | [...] | 排除选择器 |
| enablePerfLog    | boolean  | false | 性能日志   |
