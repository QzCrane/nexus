# Spectra 架构映射清单

> Generated by AI Agent `Antigravity` on 2026-01-07

## 目录结构概览

Spectra 遵循标准的 Chrome 扩展架构，核心媒体控制逻辑高度模块化。

```plaintext
src/
├── background/         # Service Worker (持久化逻辑/消息路由)
├── content/            # Content Scripts (页面注入/Dom与音频控制)
├── popup/              # 扩展弹出界面 (React)
├── offscreen/          # 离屏文档 (音频处理核心/WebAudio)
├── injector/           # 注入脚本 (Main world 权限/API劫持)
└── shared/             # 共享工具与类型
```

## 模块详解

### 1. Content Script (`src/content/`)

业务核心，注入网页控制 `<video>`/`<audio>`。

| 模块      | 路径     | 职责                                                                                                |
| :-------- | :------- | :-------------------------------------------------------------------------------------------------- |
| **Logic** | `logic/` | **业务中枢**。`policy-executor`(策略执行), `mode-executor`(模式切换), `message-handler`(消息分发)。 |
| **Core**  | `core/`  | **基础设施**。`index.ts`(启动), `lifecycle/`(保活/观察者), `context-guard`(环境检查)。              |
| **Audio** | `audio/` | **音频控制**。`capture-manager`(TabCapture 流), `dom-volume`(原生音量)。                            |
| **Video** | `video/` | **视频画面**。`transform`(旋转/镜像), `filter`(滤镜), `ab-loop`(循环), `time-marker`(标记)。        |
| **Input** | `input/` | **交互输入**。`hotkey-*`(全键盘操作), `controllers`(快捷键动作映射)。                               |
| **UI**    | `ui/`    | **屏幕反馈**。`osd`(音量条), `toast`(操作提示)。                                                    |
| **Utils** | `utils/` | **辅助工具**。`focus-helper`(焦点模拟), `pause-tracker`(暂停状态)。                                 |

### 2. Background (`src/background/`)

后台服务，负责全局状态协调与 Chrome API 代理。

| 文件                | 职责                            |
| :------------------ | :------------------------------ |
| `index.ts`          | 入口。初始化各大监听器。        |
| `helpers.ts`        | 徽章(Badge)管理、Tab 查询工具。 |
| `remote-service.ts` | 远程控制服务 (WebRTC/Socket)。  |
| `lifecycle.ts`      | 安装/更新/卸载事件处理。        |
| `handlers/`         | 针对特定网站的特殊处理逻辑。    |

### 3. Offscreen (`src/offscreen/`)

**音频引擎核心**。由于 Service Worker 无法访问完整 DOM/WebAudio API，此处承载所有高级音频处理 (EQ/Dynamics/Spatial)。

- **自动休眠**: 无会话连接时自动关闭以节省资源。
- **通信**: 通过 Runtime Message 与 Background/Content 交换音频数据与配置。

### 4. Injector (`src/injector/`)

运行在页面主世界 (Main World)。

- **API 劫持**: 覆盖 `AudioContext` 以解决部分网站的反劫持或独占逻辑。
- **全屏兼容**: 协助 Content Script 处理全屏时的 DOM 状态同步。

## 架构决策记录

- **策略模式**: `PolicyExecutor` 动态决定使用 `Native` (轻量) 还是 `Capture` (强力) 模式，取决于 CORS 状态与用户交互。
- **零拷贝**: 音频可视化数据通过 `Uint8Array` 直接传递，禁止序列化为普通数组。
- **单一边界**: 所有配置变更必须通过 `PolicyExecutor` 统一入口，禁止各模块私自修改 State。
- **双向同步**: 页面 UI 与插件状态双向同步，使用 `settingByPlugin` 标志位防止循环更新。详见 [bidirectional-sync-principles.md](./bidirectional-sync-principles.md)。
