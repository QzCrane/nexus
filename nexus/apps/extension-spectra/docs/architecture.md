## 模块详解

### 1. Content Script (`src/content/`)

核心职责: 注入目标页面接管音像系统

- Logic: `logic/` | 业务中枢 (`policy-executor`/`mode-executor`/`message-handler`)
- Core: `core/` | 基础设施 (`index.ts`/`lifecycle`/`context-guard`)
- Audio: `audio/` | 音频劫持 (`capture-manager`/`dom-volume`)
- Video: `video/` | 画面操作 (`transform`/`filter`/`ab-loop`/`time-marker`)
- Input: `input/` | 键盘/外设响应 (`hotkey-*`/`controllers`)
- UI: `ui/` | 视觉反馈 (`osd`/`toast`)
- Bridge: `logic/site-bridge/` | 站点网桥 (Pinnacle Registry 同步复杂站点级 API)
- Utils: `utils/` | 状态辅助 (`focus-helper`/`pause-tracker`)

### 2. Background (`src/background/`)

核心职责: WebExtension 守护进程与跨边界路由

- `index.ts`: 核心入口绑定
- `helpers.ts`: 徽章(Badge)管理 / Tab 查询
- `remote-service.ts`: 远控服务器桥接 (WebRTC/WS)
- `lifecycle.ts`: Tab 状态感知 (OnActivated/OnUpdated/OnRemoved)
- `upgrade-manager.ts`: 跨版本热更 / 脚本兜底注射引擎
- `handlers/`: 领域消息解析路由 (`audio`/`capture`/`registry` 等)

### 3. Offscreen (`src/offscreen/`)

**音频引擎核心**。由于 Service Worker 无法访问完整 DOM/WebAudio API，此处承载所有高级音频处理 (EQ/Dynamics/Spatial)。

- **自动休眠**: 无会话连接时自动关闭以节省资源。
- **通信**: 通过 Runtime Message 与 Background/Content 交换音频数据与配置。

### 4. Injector (`src/injector/`)

运行在页面主世界 (Main World)。

- **API 劫持**: 覆盖 `AudioContext` 以解决部分网站的反劫持或独占逻辑。
- **全屏兼容**: 协助 Content Script 处理全屏时的 DOM 状态同步。

## 架构决策记录

- **策略模式**: `PolicyExecutor` 动态决定使用 `Native` (轻量) 还是 `Capture` (强力) 模式，取决于 CORS 状态与用户交互。
- **零拷贝**: 音频可视化数据通过 `Uint8Array` 直接传递，禁止序列化为普通数组。
- **单一边界**: 所有配置变更必须通过 `PolicyExecutor` 统一入口，禁止各模块私自修改 State。
- **双向同步**: 页面 UI 与插件状态双向同步，使用 `settingByPlugin` 标志位防止循环更新。详见 [bidirectional-sync-principles.md](./bidirectional-sync-principles.md)。
- **零刷新热更新**: 扩展更新后通过 `upgrade-manager` + `sentinel` DOM stub 无缝迁移状态，无需用户刷新页面。Popup 含 fallback 自动注入重试。详见 [protocols.md](./protocols.md#热更新协议)。
