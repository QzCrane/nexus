# SPECTRA - Chrome 웹스토어 (한국어)

## 이름

SPECTRA - 볼륨 부스터, EQ & 미디어 컨트롤

## 짧은 설명

800% 볼륨 부스트, 10밴드 EQ, 동영상 제어, 모바일 리모컨. 네이티브급 경험, 최적화된 성능, 바로 사용 가능.

## 상세 설명

🚀 **왜 SPECTRA인가? 다른 확장 프로그램들은 문제가 있습니다.**

이런 확장 프로그램에 지치셨나요:
❌ 페이지 열 때 랜덤으로 음소거?
❌ 예상치 못한 페이지 새로고침?
❌ F11 없이 동영상 전체화면 불가?
❌ 복잡하고 사용하기 어려운 인터페이스?

**SPECTRA는 이 모든 문제를 해결합니다.**

---

✅ **SPECTRA의 차별점**

• **랜덤 음소거 없음** - 설정한 볼륨 유지
• **페이지 새로고침 문제 없음** - 마우스 자유롭게 이동, 문제 없음
• **진정한 전체화면** - 원클릭, F11 필요 없음
• **항상 작동** - TikTok, Netflix 등 CORS 보호 사이트에서도

🎨 **깔끔하고 직관적인 UI**

• **원클릭 컨트롤** - 메뉴 찾기 불필요
• **시각적 EQ 커브** - 실시간 조정 확인
• **다크/라이트 테마** - 취향에 맞게
• **다국어 지원** - 영중일한서프독러

---

🎵 **오디오 기능**

• **볼륨 800%까지 부스트** - 조용한 동영상 증폭
• **10밴드 이퀄라이저** - 32Hz에서 16kHz까지 미세 조정
• **컴프레서 & 리미터** - 고볼륨에서도 왜곡 없음
• **베이스 부스트** - 강력한 저음
• **스테레오 밸런스** - 좌우 채널 조정
• **오디오 딜레이** - 오디오와 비디오 동기화

---

🎬 **비디오 기능**

• **재생 속도** - 0.25x에서 16x
• **비디오 회전** - 90°/180°/270°
• **미러/플립** - 수평 미러링
• **PIP** - 플로팅 비디오 윈도우
• **스크린샷** - 모든 프레임 캡처
• **AB 루프** - 모든 구간 반복

---

⌨️ **키보드 단축키**

• **70개 이상의 설정 가능한 동작**
• **Chrome 전역 단축키**
• **사이트별 설정**

---

📱 **리모컨**

• **스마트폰으로 제어** - QR 스캔, 앱 설치 불필요
• **멀티 세션 지원** - 여러 탭 동시 제어
