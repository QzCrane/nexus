# SPECTRA - Chrome Web Store (한국어)

## 이름

SPECTRA - 볼륨 부스터, EQ & 미디어 컨트롤

## 요약 (132자 이내)

800% 볼륨 부스트, EQ, 비디오 제어, 모바일 리모컨. 🔵🟣 극한 성능의 듀얼 모드 전환, 모든 사이트 호환.

## 상세 설명

🚀 **왜 SPECTRA인가요? 다른 확장 프로그램들은 부족하기 때문입니다.**

기존 볼륨 부스터를 쓰면서 이런 문제를 겪지 않으셨나요?
❌ 새 페이지를 열 때마다 갑자기 음소거가 됨
❌ 전체 화면이 제대로 안 돼서 F11을 눌러야 함
❌ 볼륨을 조절하면 페이지가 새로고침되거나 버벅임
❌ 쓸데없이 CPU를 많이 잡아먹어 노트북이 뜨거워짐

**SPECTRA는 이 모든 문제를 해결했습니다.**

---

🔵🟣 **독자 코어: 극한 성능 듀얼 모드**

SPECTRA는 업계 최고의 지능형 듀얼 모드 자동 전환 기술을 탑재했습니다.

• 🔵 **네이티브 모드 (Native)**: 브라우저 기본 엔진을 직접 이용해 소리를 증폭합니다. **CPU 추가 소모 0**, 지연 없음, 최고의 음질을 유지합니다.
• 🟣 **캡처 모드 (Capture)**: 복잡한 크로스 도메인 오디오에서 자동 활성화되어 TikTok, Netflix, Disney+ 등 모든 사이트에서 안정적으로 작동합니다.

---

✅ **SPECTRA만의 특별한 장점**

• **방해 없는 경험**: 설정한 볼륨이 항상 유지됩니다. 마음대로 음소거되지 않습니다.
• **진정한 전체 화면**: 클릭 한 번으로 완벽한 전체 화면 모드 진입. F11은 더 이상 필요 없습니다.
• **모든 사이트 호환**: 보안이 걸린 미디어 사이트에서도 변함없이 안정적인 출력을 제공합니다.
• **초경량 최적화**: 코드 다이어트와 로직 최적화로 배터리를 아끼고 시스템 리소스를 점유하지 않습니다.

🎵 **오디오 기능 Korean**
• **800% 볼륨 증폭** - 작은 소리영상을 시원하게 키워줍니다.
• **10밴드 프로 이퀄라이저** - 32Hz부터 16kHz까지 정밀한 튜닝.
• **네이티브 컴프레서/리미터** - 높은 볼륨에서도 찢어지는 소리 없이 깨끗한 음질.
• **베이스 부스트** - 깊고 웅장한 저음을 느껴보세요.
• **좌우 채널 밸런스** - 소리의 방향을 자유롭게 조절.

🎬 **동영상 제어**
• **재생 속도 조절** - 0.25x에서 16x까지 자유롭게.
• **회전 및 미러링** - 어떤 각도의 영상도 바르게 교정.
• **PIP(화중화)** - 작업하면서 작게 영상을 띄워보세요.
• **고화질 스크린샷** - 기억하고 싶은 순간을 즉시 캡처.
• **AB 반복 재생** - 학습이나 반복 시청에 큰 도움이 됩니다.

📱 **기기 간 원격 제어**
• **스마트폰 즉시 리모컨** - QR 코드 스캔 한 번으로 끝. 앱 설치 없이 폰이 리모컨이 됩니다.
• **멀티 탭 관리** - 폰에서 여러 개의 영상 탭을 간편하게 전환하고 제어하세요.
