# SPECTRA - Chrome Web Store（日本語）

## 名称

SPECTRA - 音量、イコライザー、メディア操作

## 概要（132 文字以内）

最大 800% の音量、10 バンド EQ、メディア・動画操作、任意で認証付きスマホリモコンを利用できます。

## 詳細説明

SPECTRA は、音声、再生、動画の操作を 1 つの Chrome 拡張機能にまとめます。設定とメディア処理は、既定では端末内に保持されます。

### 音声

- 最大 800% の音量調整
- 32 Hz～16 kHz の 10 バンドイコライザー
- 低音、コンプレッサー、モノラル、左右バランス、遅延
- メディアのミュートとブラウザータブのミュートを別々に管理

大きな増幅は、歪みや安全でない音量につながる場合があります。少しずつ音量を上げ、音源と再生機器に合わせてコンプレッサーを使用してください。

### 再生と動画

- 再生速度、再生/一時停止、シーク、ループ、マーカー、AB ループ
- 回転、反転、フィル、フィルター、背景の暗転
- ブラウザー標準機能によるピクチャーインピクチャーと全画面表示
- 現在のページとメディアが許可する場合の、表示中フレームのスクリーンショット

利用可否は、ページ、メディア要素、ブラウザー対応、権限、ユーザー操作の条件によって異なります。SPECTRA は、すべてのサイトで同じ結果を保証せず、対応していない操作を明示します。

### 任意のスマホリモコン

ペアリングセッションを作成し、QR コードを読み取ると、スマートフォンから選択したタブを操作できます。状態の受信やコマンド送信の前に、HMAC-SHA-256 認証を完了する必要があります。

リモコンは既定でオフです。有効にすると、Cloudflare Pages、PeerJS シグナリング、STUN、TURN サービスを使用します。認証後、選択したタブのタイトル、ドメイン、メディア操作状態がペアリング端末と交換される場合があります。ページ本文、favicon、音声、動画はリモート経路では送信されません。

### 設定とショートカット

- ローカルの全体設定とサイト別設定
- 設定可能なメディア操作ショートカット
- 多言語 UI
- ポップアップと認証済みリモコンで共有される、確認済みの実状態

### プライバシー

SPECTRA には、広告、分析、テレメトリー、開発者運営のデータ収集サービスはありません。設定とメディア処理は既定でローカルに残ります。任意のリモコン通信については、上記およびプライバシーポリシーで説明しています。

SPECTRA は、ブラウザーのセキュリティ、権限、保護されたコンテンツの制限、ユーザー操作要件を回避しません。
