## Name

SPECTRA - Advanced Media Control

## Short Description (132 chars max)

800% volume boost, 10-band EQ, video rotation/mirror, playback speed, mobile remote control. Works on any website!

## Detailed Description

🎵 **SPECTRA** - The ultimate media control extension for Chrome

### 🔊 Audio Features

• **Volume Boost up to 800%** - Amplify quiet videos and audio
• **10-Band Equalizer** - Fine-tune frequencies from 32Hz to 16kHz
• **Compressor & Limiter** - Prevent distortion at high volumes
• **Bass Boost** - Enhance low frequencies
• **Stereo Balance** - Adjust left/right audio channels
• **Audio Delay** - Sync audio with video

### 🎬 Video Features

• **Playback Speed** - 0.25x to 16x speed control
• **Video Rotation** - Rotate 90°/180°/270°
• **Mirror/Flip** - Horizontal video mirroring
• **Picture-in-Picture** - Floating video window
• **Screenshot** - Capture current frame
• **Background Dimming** - Focus on video content

### ⌨️ Keyboard Shortcuts

• **70+ Configurable Actions** - Customize your workflow
• **Chrome Global Shortcuts** - Work from any tab
• **Per-Site Configuration** - Different shortcuts per website

### 📱 Remote Control

• **Mobile Remote** - Control from your phone
• **QR Code Connection** - Easy setup
• **Multi-Session Support** - Control multiple tabs

### 🌍 Multi-Language Support

Supported languages: English, 简体中文, 日本語, 한국어, Español, Français, Deutsch, Русский

### 💡 How It Works

SPECTRA uses Web Audio API for lossless audio processing. For CORS-protected content, it uses Chrome's Tab Capture API to ensure maximum compatibility.

### 🔒 Privacy

• No data collection
• All settings stored locally
• No external servers (except for optional remote control)
