# Extension SPECTRA

**用途**: 扩展各端实现 (Popup/Content/Background/Offscreen/Options)。

## 职责映射

- Background: badge.ts 角标 / handlers/ 路由 / remote-\*.ts 遥控 / shortcuts.ts
- Content: policy-executor/ 模式切换 / hotkey-\*.ts 网站快捷键
- Offscreen: Capture 音频处理
- Offscreen-Remote: 多会话 PeerJS WebRTC
- Popup: side-panel/ 视频控件 / views/ 设置
- Options: 快捷键配置 (Chrome Slots + 网站独立)

## 快捷键系统 (双轨)

### Chrome 全局快捷键 (manifest commands)

| 预设              | 默认按键 |
| ----------------- | -------- |
| volume_up/down    | Alt+↑/↓  |
| toggle_mute       | Alt+M    |
| speed_up          | Alt+S    |
| slot_01 ~ slot_16 | 用户自定 |

Background 监听 → 查 slotMapping → 执行 action

### 网站独立配置 (默认关闭)

```typescript
sites: Record<string, { enabled: boolean; bindings: HotkeyBinding[] }>;
```

用户在 Options 页按域名启用并自定义

## 角标逻辑 (Sticky Badge v4)

- 显示条件: 用户通过插件 UI 操作任何配置 (含 0-100%音量)
- 不显示: 只打开 UI 不操作 / 网站自己调节
- 捕获模式: 自动激活 sticky
- 锁存: 一旦激活，该标签页永久显示角标
