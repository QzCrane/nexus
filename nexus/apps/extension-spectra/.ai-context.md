# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录          | 职责                 |
| ------------- | -------------------- |
| `background/` | Service Worker       |
| `content/`    | 页面音频/视频控制    |
| `popup/`      | Popup UI + 侧边面板  |
| `offscreen/`  | Tab Capture 音频处理 |

## Content 模块

| 文件                       | 职责                      |
| -------------------------- | ------------------------- |
| `pause-tracker.ts`         | 暂停时间戳追踪 (pausedAt) |
| `media-control.ts`         | 播放/暂停/PiP/速度        |
| `video-transform.ts`       | 旋转/镜像/截图/全屏/裁剪  |
| `media-message-handler.ts` | 媒体消息路由              |

## 暂停保留 (v1.x+)

- `GlobalSettings.pauseRetentionSeconds` (默认 60s, 0=永久)
- 检查点：`popup/card/init.ts` → 时间差比较
- 数据源：`content/pause-tracker.ts` → pausedAt timestamp

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`，使用 `Actions` 常量

## 禁止

- 硬编码 Action 字符串
- 添加 URL 路径检测规则
