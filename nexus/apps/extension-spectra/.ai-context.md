# Extension SPECTRA

**用途**：Chrome 扩展入口 (Popup + Content + Background)

## 入口点

| 文件                      | 用途            |
| ------------------------- | --------------- |
| `src/popup/index.ts`      | Popup UI        |
| `src/content/index.ts`    | 注入网页 (入口) |
| `src/background/index.ts` | Service Worker  |

## 通信流

```text
Popup ↔ Background ↔ Content
              ↓
         Offscreen (Capture)
```

## 核心

- **PolicyEngine**：唯一决策大脑 → 策略详见 `docs/policy-decision.md`

## 约束

- MV3：无持久状态，用 chrome.storage
- AudioContext：需在用户手势后创建
- E2E 测试：修改后必须遵循 `/feature-finish`
