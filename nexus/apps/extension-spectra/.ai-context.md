# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录              | 职责                   |
| ----------------- | ---------------------- |
| `src/background/` | Service Worker         |
| `src/content/`    | 页面音频/视频控制      |
| `src/popup/`      | Popup UI + 侧边面板    |
| `src/offscreen/`  | Tab Capture 音频处理   |
| `public/`         | 静态资源 + injector.js |

## Content 模块

| 文件                       | 职责                     |
| -------------------------- | ------------------------ |
| `media-control.ts`         | 播放/暂停/PiP/速度       |
| `video-transform.ts`       | 旋转/镜像/截图/全屏/裁剪 |
| `video-filter.ts`          | 亮度/对比度/灰度/反色    |
| `media-message-handler.ts` | 媒体消息路由             |
| `message-handler.ts`       | 核心消息处理             |

## AudioConfig 扩展字段

| 字段    | 范围      | 说明         |
| ------- | --------- | ------------ |
| `pan`   | -1 ~ 1    | 声道平衡     |
| `delay` | 0 ~ 500ms | 声画同步延迟 |

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`，使用 `Actions` 常量

## 禁止

- 硬编码 Action 字符串
- 添加 URL 路径检测规则
