# Extension SPECTRA

**用途**：Chrome 扩展入口 (Popup + Content + Background + Offscreen)

## 入口点

| 文件 | 用途 |
| `src/popup/index.ts` | Popup UI |
| `src/content/index.ts` | 注入网页 |
| `src/background/index.ts` | Service Worker |
| `src/offscreen/index.ts` | 音频劫持处理 |

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`，消息必须用 `Actions` / `OffscreenActions` 常量

## userRegistry

首次安装用 `DefaultRestrictedDomains` 初始化，之后用户完全控制 + CORS 自动添加

## ❌ 禁止

- 硬编码 Action 字符串
- 添加 URL 路径检测
- 重复定义常量
