# Extension SPECTRA 上下文

**核心职责**：插件各端实现 (Popup, Content, Background, Offscreen)

## 模块职责

- `background/badge.ts`：角标状态管理，感知交互状态。
- `content/badge-sync.ts`：角标同步 Hash 去重。
- `popup/side-panel/`：基于 Grid + Double RAF 的稳定布局动效。

## 角标逻辑 v2.0 (三原则)

1. **交互定义**：仅限数值调节触发；排除 `enabled` 开关切换。
2. **劫持即使用**：进入有效的 `Capture` 模式自动视为用户交互。
3. **可见性规则**：
   - 未交互：默认配置 (100%音量,未静音,非劫持) 下隐藏角标。
   - 已交互：状态锁存 (Sticky)，后续即便恢复默认配置也继续显示。
   - 隐身性：仅打开 UI 不触发角标，确保用户无感。

## 运行机制

- **跟随模式**：网站原生音量优先，插件状态主动同步。
- **高级模式**：GainNode 控制，仅同步静音状态。
- **持久化**：原生音量变化自动保存至域名存储。
- **任务**：`stateReapply` (3s, 隐藏时跳过), `mediaReport` (5s)。
