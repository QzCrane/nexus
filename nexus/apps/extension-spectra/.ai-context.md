# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录          | 职责                 |
| ------------- | -------------------- |
| `background/` | Service Worker       |
| `content/`    | 页面音频/视频控制    |
| `popup/`      | Popup UI + 侧边面板  |
| `offscreen/`  | Tab Capture 音频处理 |

## Content 模块

| 文件                           | 职责                     |
| ------------------------------ | ------------------------ |
| `media-control.ts`             | 播放/暂停/PiP/速度       |
| `video-transform.ts`           | 旋转/镜像/截图/全屏/裁剪 |
| `video-filter.ts`              | 滤镜/背景变暗            |
| `ab-loop.ts`, `time-marker.ts` | AB 循环/时间标记         |
| `media-message-handler.ts`     | 媒体消息路由             |

## AudioConfig 扩展 (pan/delay)

`Source → Gain → Bass → EQ[10] → Comp → Panner → Delay → Analyser → Dest`

Native + Capture 使用相同节点链，跨域网站全功能支持

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`，使用 `Actions` 常量

## 禁止

- 硬编码 Action 字符串
- 添加 URL 路径检测规则
