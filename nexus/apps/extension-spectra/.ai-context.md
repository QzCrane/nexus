# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录              | 职责                   |
| ----------------- | ---------------------- |
| `src/background/` | Service Worker         |
| `src/content/`    | 注入网页音频控制       |
| `src/popup/`      | Popup UI + 侧边面板    |
| `src/offscreen/`  | Tab Capture 音频处理   |
| `docs/`           | 策略文档               |
| `public/`         | 静态资源 + injector.js |

## 侧边面板

点击卡片图标展开左侧 260px 面板，复用 `visualizer/MetricsCache` + `drawEqCurve`

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`，使用 `Actions` 常量

## 策略

纯 CORS 检测驱动，无默认列表，首次安装空注册表

## 禁止

- 硬编码 Action 字符串
- 添加 URL 路径检测规则
