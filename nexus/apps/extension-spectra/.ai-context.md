# Extension SPECTRA

扩展各端: Popup/Content/Background/Offscreen/Options

## 依赖

@nexus/contracts | @nexus/kernel | @nexus/audio-engine

## 职责

- Background: badge.ts 角标 / handlers/ 路由 (含 user-scripts.ts) / remote-\*.ts 遥控 / shortcuts.ts
- Content: policy-executor/ 模式切换 / lifecycle/ 用户交互+全屏处理 / capture-manager.ts 劫持状态
- Injector: MAIN world 拦截 (AudioContext 劫持/全屏音量/CORS 强制)
- Store-Listings: 9 国语言商店描述 / 隐私政策声明 (发布必看)
- Offscreen: Capture 音频处理
- Offscreen-Remote: 多会话 PeerJS WebRTC
- Popup: side-panel/ 视频控件 / views/ 设置
- Options: 快捷键配置 (Chrome Slots + 网站独立)
- Shared: logger.ts / smooth-scroll.ts (本地实现)

## 文档

- 规划: plan.md
- 决策: docs/policy-decision.md

## 快捷键 (双轨)

**Chrome 全局** (manifest commands): Alt+↑/↓ 音量, Alt+M 静音, Alt+S 速率, slot_01~16 用户定

**网站独立** (默认关闭): `sites: Record<domain, { enabled, bindings }>`

## Badge (Sticky v4.1)

激活条件: 捕获模式 / 预设>100% / UI 操作任意配置
不显示: 仅开 UI 不操作 / 网站自调
锁存: 激活后永久显示

## 全屏处理 (Capture Only)

触发条件: `isCaptureActive === true` (由 capture-manager 通过 postMessage 同步)
流程: 暂停 capture → 重置 DOM 音量 100% → 全屏完成 → 恢复 capture → applyState() 恢复配置
非 CAPTURE 模式: 直接放行，不干预

## CORS 检测

时机: 首次用户交互后触发 (避免 AudioContext Autoplay 报错)
入口: user-interaction.ts → probeCors() → audioController.initialize()
