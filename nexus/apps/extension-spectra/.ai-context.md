# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录结构

| 目录/文件         | 职责                                |
| ----------------- | ----------------------------------- |
| `src/background/` | Service Worker                      |
| `src/content/`    | 注入网页的音频控制                  |
| `src/popup/`      | Popup UI                            |
| `src/offscreen/`  | Tab Capture 音频处理                |
| `src/shared/`     | 跨模块共享 (logger)                 |
| `docs/`           | 策略文档                            |
| `public/`         | 静态资源 + injector.js (MAIN world) |

## 侧边面板 (side-panel/)

- 点击卡片图标展开左侧 260px 面板
- 布局：fixed 定位 `right:390px`，高度与主 UI 等高
- 动态宽度：收起 390px，展开 650px，**无动画**
- EQ 曲线：复用 `visualizer/MetricsCache` + `drawEqCurve`

## 受限域名策略 (v3.1)

**纯 CORS 检测驱动，无默认列表**

- 首次安装：空注册表
- 访问页面时：CORS 预检测 → 结果入表
- 策略切换：直接查表

## 通信

`Popup ↔ Background ↔ Content ↔ Offscreen`

消息必须使用 `Actions` / `OffscreenActions` 常量

## ❌ 禁止

- 硬编码 Action 字符串
- 使用默认域名列表（已删除）
- 添加 URL 路径检测规则
