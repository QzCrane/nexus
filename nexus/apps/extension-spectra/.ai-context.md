# SPECTRA 上下文 (v4.3.0)

DNA: Popup/Core-Logic/Offscreen-Capture | 栈: @nexus/{contracts, kernel, audio-engine}

## 职责

- Background: Badge, User-Scripts Router, Remote(WebRTC), Shortcuts(System-Level)
- Content:
  - Logic: Policy/Mode Executor (业务中枢)
  - Audio/Video: Capture & DOM 操控 / 画面变换
  - Input: Hotkey Listener (Site-Level)
  - Core: Lifecycle, Settings, State Guard
- Injector: MAIN world (WebAudio Hijack, Fullscreen Volume Fix)
- Offscreen: Tab-Capture WebAudio (Zero-Copy Transfer | Auto-Cleanup)
- UI: Popup(React), Options, Shared(SmoothScroll)

## 核心机制

- 策略中心: PolicyExecutor 统一调度 Native/Capture 模式切换
- 状态同步: Config 变更 → UpdateConfig → ApplyState → Badge/UI Broadcast
- 音频流: CaptureManager (Content) ↔ Offscreen (Processing) ↔ Background (Coordination)

## 约束

- 结构: src/content 必须分层 (core/logic/audio/video/input/ui)
- 性能: 观察者必须 Debounce ( DOM 500ms / Nav 300ms )
- 安全: CORS 探测必须依赖 User Gesture | 敏感 API (Scripting) 走 Background
