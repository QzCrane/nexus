# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录          | 职责                 |
| ------------- | -------------------- |
| `background/` | Service Worker       |
| `content/`    | 页面音频/视频控制    |
| `popup/`      | Popup UI + 侧边面板  |
| `offscreen/`  | Tab Capture 音频处理 |

## Popup 关键模块

| 路径                           | 职责                  |
| ------------------------------ | --------------------- |
| `side-panel/registry.ts`       | 卡片配置注册          |
| `side-panel/footer-actions.ts` | Reset/Save 效果预设   |
| `views/i18n-apply.ts`          | 语言切换 + 动态 title |

## 双预设系统

| 预设  | Key 格式              | 内容         |
| ----- | --------------------- | ------------ |
| 主 UI | `preset_vol_{domain}` | 音量         |
| 侧边  | `preset_fx_{domain}`  | EQ/Pan/Delay |

## 暂停保留

`GlobalSettings.pauseRetentionSeconds` → `pause-tracker.ts`

## 禁止

- 硬编码 Action | URL 路径规则
