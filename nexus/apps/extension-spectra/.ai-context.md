# Extension SPECTRA

**用途**：Chrome 扩展 (Popup + Content + Background + Offscreen)

## 目录

| 目录          | 职责                 |
| ------------- | -------------------- |
| `background/` | Service Worker       |
| `content/`    | 页面音频/视频控制    |
| `popup/`      | Popup UI + 侧边面板  |
| `offscreen/`  | Tab Capture 音频处理 |

## 关键模块

| 路径                           | 职责                    |
| ------------------------------ | ----------------------- |
| `content/dom-volume.ts`        | DOM 音量 + 跟随模式     |
| `content/mode-executor.ts`     | 模式执行 + 原生音量同步 |
| `background/handlers/badge.ts` | 角标 userInteracted     |
| `popup/side-panel/`            | 侧边面板逻辑与动效      |

## UI 架构

- **Popup 布局**：`Grid Layout` + `justify-content: end`
  - 目的：解决 Chrome 扩展窗口动态变宽时的左侧抖动问题。
  - 策略：利用 Grid 的强约束力锚定右侧。
  - **动效**：`Double RAF` 确保 Frame 稳定后触发 `Transition`。
  - **层级**：SidePanel (`z-90`) 从 MainUI (`z-100`) 下方滑出，掩盖渲染瑕疵。

## 音量策略

- **跟随模式**：网站原生音量优先，插件配置跟随同步
- **高级模式**：GainNode 控制，仅同步静音状态
- **原生音量变化**：自动保存到域名存储 (AUDIO_SET_CONFIG)

## 角标规则

- 用户未交互 + 默认配置 → 不显示
- 用户已交互 或 配置非默认 → 显示

## 定时任务

| 任务         | 间隔 | 页面隐藏时 |
| ------------ | ---- | ---------- |
| stateReapply | 3s   | 跳过       |
| mediaReport  | 5s   | 正常       |

## 禁止

- 硬编码 Action | URL 路径规则
