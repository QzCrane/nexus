# Extension SPECTRA Context

**Role**: Extension Implementation (Popup, Content, Background, Offscreen)

## Path Responsibilities

- `background/badge.ts`: Badge logic (`userInteracted` aware).
- `content/badge-sync.ts`: Badge status sync hash.
- `popup/side-panel/`: Layout-stable animation (Grid + Double RAF).

## Badge Rules v2.0

- **Interaction**: Only explicit value adjustments (excluding `enabled` toggle) or effective `Capture` mode activation trigger `userInteracted`.
- **Visibility**:
  - `userInteracted = false`: Hidden if default config (vol 100%, !muted, !capture).
  - `userInteracted = true`: Sticky activation. Always shows badge even if back to default.
- **Stealth**: Opening UI or toggling `enabled` does NOT activate badge unless it triggers capture.

## Operations

- **Follow Mode**: Site native volume priority, plugin syncs state.
- **Advanced Mode**: GainNode control, mute sync only.
- **Sync**: Config saved to domain storage on native changes.
- **Tasks**: `stateReapply` (3s, skip if hidden), `mediaReport` (5s).
