# Content Script

**用途**: 注入网页，音频控制 + CORS 检测。

## 文件

- index.ts: 入口，初始化模块
- capture-manager.ts: Capture 请求管理
- dom-volume.ts: DOM 音量 (0-100%)
- mode-executor.ts: 模式切换执行
- osd.ts / toast.ts: 屏幕提示

## 子目录

- policy-executor/: CORS 检测 + 策略执行
- lifecycle/: 观察器 + 定时器

## 数据流

加载 → initCorsStatus() → PolicyExecutor → executeMode()
↓
probeCorsOnMediaDetected() → 结果入表
