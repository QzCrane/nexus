# Content Script 上下文

## 模块架构 (统一后)

```
content/
├── core/              # [构建入口] 启动 + 生命周期
│   ├── index.ts       # 主入口 (build target)
│   ├── lifecycle/     # 媒体观察器, 定时器, 用户交互, 全屏处理
│   ├── settings-manager.ts
│   └── context-guard.ts
├── logic/             # [业务逻辑] 策略 + 模式 + 消息
│   ├── policy-executor/  # CORS 检测, badge 同步, config 更新
│   ├── mode-executor.ts  # WebAudio/Capture/NativeLite 切换
│   ├── message-handler.ts
│   └── media-*.ts
├── audio/             # [音频控制] DOM 音量 + Capture
│   ├── dom-volume.ts
│   ├── volume-observer.ts
│   └── capture-manager.ts
├── input/             # [键盘] Hotkey 系统
├── video/             # [视频] 变换/滤镜/循环/标记
├── ui/                # [视觉反馈] OSD, toast
├── utils/             # [工具] focus, pause tracker
└── types/             # [类型定义] PolicyExecutorState 等
```

## 核心机制

注入: 单例锁 `__SPECTRA_INJECTED__`
通信: MessageHandler ↔ Background/Popup
策略: PolicyExecutor (CORS 探测 → Capture/Native 切换)

## 快捷键系统

Chrome: Manifest Commands (全局/系统级)
Site: Keydown Listener (页面级/默认关闭/需配置)
