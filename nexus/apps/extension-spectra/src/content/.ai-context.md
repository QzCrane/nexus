# Content Script

**用途**：注入网页，负责音频控制和 CORS 检测

## 文件索引

| 文件                  | 职责                  |
| --------------------- | --------------------- |
| `index.ts`            | 入口，初始化所有模块  |
| `capture-manager.ts`  | Capture 模式请求管理  |
| `context-guard.ts`    | 扩展上下文有效性检查  |
| `dom-volume.ts`       | DOM 音量控制 (0-100%) |
| `message-handler.ts`  | 消息路由              |
| `mode-executor.ts`    | 模式切换执行          |
| `osd.ts`              | 屏幕提示              |
| `settings-manager.ts` | 全局设置缓存          |
| `toast.ts`            | Toast 提示            |
| `types.ts`            | 类型定义              |

## 子目录

| 目录               | 职责                     |
| ------------------ | ------------------------ |
| `policy-executor/` | 策略执行核心 (CORS 检测) |
| `lifecycle/`       | 生命周期 (观察器/定时器) |

## 数据流

```
页面加载 → initCorsStatus() 查表 → PolicyExecutor → executeMode()
           ↓
       probeCorsOnMediaDetected() 预检测 → 结果入表
```
