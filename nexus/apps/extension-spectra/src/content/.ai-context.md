# Content Script

**用途**：注入网页，负责音频控制和用户交互

## 核心模块

| 目录/文件            | 职责                      |
| -------------------- | ------------------------- |
| `policy-executor/`   | 策略执行（核心）          |
| `lifecycle/`         | 生命周期（观察器/定时器） |
| `mode-executor.ts`   | 模式切换                  |
| `message-handler.ts` | 消息处理                  |

## 数据流

```
页面加载 → index.ts → PolicyExecutor → executeMode()
```

## 约束

- 使用 `safeSend` 包装 chrome.runtime 调用
- 扩展重载后 context 会失效
- MutationObserver 回调需防抖
