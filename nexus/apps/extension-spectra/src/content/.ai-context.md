# Content Script context

## 模块架构

Core: index/lifecycle/settings/guard → 启动+保活
Logic: policy/mode/msg/media-ctrl → 业务中枢
Audio: capture/dom-volume → 音频流控制
Video: transform/filter/loop/marker → 画面操作
Input: hotkey-{listener,actions,helpers} → 键鼠交互
UI: osd/toast → 屏幕提示
Utils: focus/pause → 辅助工具

## 核心机制

注入: 单例锁 `__SPECTRA_INJECTED__`
通信: MessageHandler ↔ Background/Popup
策略: PolicyExecutor (CORS 检测 → 切换 Capture/Native)

## 快捷键系统

Chrome: Manifest Commands (全局/系统级)
Site: Keydown Listener (页面级/默认关闭/需配置)
