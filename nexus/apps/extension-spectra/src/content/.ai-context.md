# Content Script

**用途**: 注入网页，音频控制 + CORS 检测 + 网站独立快捷键。

## 核心文件

- index.ts: 入口，初始化各模块
- capture-manager.ts: Capture 请求管理
- dom-volume.ts: DOM 音量 (0-100%)
- mode-executor.ts: 模式切换执行
- video-transform.ts: 旋转/镜像/截图/全屏
- media-control.ts: 播放/PiP/速率/跳转
- osd.ts / toast.ts: 屏幕提示

## 网站快捷键模块 (默认关闭)

- hotkey-listener.ts: 键盘监听 + 配置加载
- hotkey-actions.ts: 动作执行器 (70+ 动作)
- hotkey-helpers.ts: 消息通信辅助

## 快捷键架构

```typescript
// 网站配置 (默认关闭)
sites[domain].enabled = false;  // 用户需手动启用
sites[domain].bindings = [...]; // 自定义绑定
```

## 子目录

- policy-executor/: CORS 检测 + 策略执行
- lifecycle/: 观察器 + 定时器

## Chrome 全局快捷键 vs 网站快捷键

| Chrome 全局        | 网站快捷键       |
| ------------------ | ---------------- |
| manifest commands  | keydown 监听     |
| 系统级，不覆盖网站 | 页面级，可能冲突 |
| Background 处理    | Content 处理     |
| 默认启用           | 默认关闭         |
