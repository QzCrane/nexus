# Policy Executor

**用途**：根据 PolicyEngine 执行音频处理策略

## 文件结构

| 文件 | 职责 |
|-----|------|
| `index.ts` | 主入口 |
| `badge-sync.ts` | 角标更新 |
| `cors-handler.ts` | CORS 检测 |
| `config-updater.ts` | 配置更新 |

## 依赖

```
上游: @nexus/audio-engine (PolicyEngine)
下游: ../index.ts
```

## 约束

- 使用 `safeSend` 包装消息
- 使用 hash 去重避免高频更新
