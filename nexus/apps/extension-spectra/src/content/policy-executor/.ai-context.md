# Policy Executor

**用途**：策略执行核心 (CORS 检测 + 模式切换)

## 文件索引

| 文件                | 职责                            |
| ------------------- | ------------------------------- |
| `index.ts`          | createPolicyExecutor 工厂       |
| `cors-handler.ts`   | CORS 预检测 + 结果入表          |
| `badge-sync.ts`     | 角标颜色同步                    |
| `config-updater.ts` | 配置更新                        |
| `types.ts`          | 类型 (CorsStatus/InternalState) |

## CORS 检测流程

1. `initCorsStatus()` - 页面加载时查表
2. `probeCorsOnMediaDetected()` - 发现媒体时预检测
3. `setupCorsCallback()` - 策略切换时回调

## 约束

- 检测结果持久化到 `restrictedRegistry`
- 预检测不依赖用户手势
