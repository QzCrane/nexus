# Policy Executor

**用途**：策略执行核心 (CORS 检测 + 模式切换)

## 文件索引

| 文件                | 职责                            |
| ------------------- | ------------------------------- |
| `index.ts`          | createPolicyExecutor 工厂       |
| `cors-handler.ts`   | CORS 状态管理 + 回调 + 探测协调 |
| `cors-prober.ts`    | AnalyserNode 数据检测 (v3.4)    |
| `badge-sync.ts`     | 角标颜色同步                    |
| `config-updater.ts` | 配置更新                        |
| `types.ts`          | 类型 (CorsStatus/InternalState) |

## CORS 检测原理 (v3.4)

**`createMediaElementSource()` 不抛跨域错误！**

使用 `AnalyserNode.getByteFrequencyData()` 检测：

- 有数据 → SAFE
- 全零 → RESTRICTED

## 约束

- 检测需媒体正在播放 (readyState>=2)
- 结果持久化到 `restrictedRegistry`
- 探测后触发 `applyState()` 重计算模式
