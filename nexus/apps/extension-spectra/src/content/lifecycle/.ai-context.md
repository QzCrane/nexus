# Lifecycle

**用途**：Content Script 生命周期管理

## 文件索引

| 文件                    | 职责                            |
| ----------------------- | ------------------------------- |
| `index.ts`              | 统一导出                        |
| `intervals.ts`          | 定时器 (状态重应用/媒体上报)    |
| `media-observer.ts`     | MutationObserver 监听新媒体     |
| `user-interaction.ts`   | 用户手势监听                    |
| `fullscreen-handler.ts` | 全屏切换时临时暂停/恢复 Capture |

## 约束

- 定时器需在上下文失效时清理
- MutationObserver 回调需防抖
- 全屏处理需与 `public/injector.js` 配合（跨 world 通信）
