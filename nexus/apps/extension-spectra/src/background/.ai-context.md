# Background Script

**用途**：Service Worker，处理消息路由和扩展级状态

## 文件索引

| 文件           | 职责                    |
| -------------- | ----------------------- |
| `index.ts`     | 入口，注册处理器        |
| `state.ts`     | Tab 状态 + Storage 仓库 |
| `helpers.ts`   | 辅助函数                |
| `shortcuts.ts` | 快捷键处理              |
| `lifecycle.ts` | Tab 生命周期            |

## handlers/ 子目录

| 文件           | 处理消息                     |
| -------------- | ---------------------------- |
| `audio.ts`     | AUDIO\_\*                    |
| `badge.ts`     | BADGE\_\*                    |
| `capture.ts`   | CAPTURE\_\* + Offscreen      |
| `registry.ts`  | REGISTRY\_\* (CORS 检测结果) |
| `settings.ts`  | SETTINGS\_\*                 |
| `tab-state.ts` | TAB\_\*                      |

## MV3 约束

- 无持久状态 → `chrome.storage`
- 30 秒超时 → 长操作分片
