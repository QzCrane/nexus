# Background Script

**用途**: Service Worker，消息路由 + 扩展级状态。

## 文件

- index.ts: 入口，注册处理器
- state.ts: Tab 状态 + Storage
- shortcuts.ts: 快捷键处理
- lifecycle.ts: Tab 生命周期

## handlers/

- audio.ts: AUDIO\_\*
- badge.ts: BADGE\_\*
- capture.ts: CAPTURE\_\* + Offscreen
- registry.ts: REGISTRY\_\*
- settings.ts: SETTINGS\_\*

## MV3 约束

- 无持久状态 → chrome.storage
- 30s 超时 → 长操作分片
