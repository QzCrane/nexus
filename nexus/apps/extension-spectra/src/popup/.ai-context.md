# Popup UI

**用途**：用户主界面 (音量/EQ/可视化/设置)

## 文件索引

| 文件       | 职责     |
| ---------- | -------- |
| `index.ts` | 入口     |
| `types.ts` | 类型定义 |

## 子目录

| 目录          | 职责                                  |
| ------------- | ------------------------------------- |
| `card/`       | 标签页卡片 (init/render/events)       |
| `visualizer/` | 频谱可视化                            |
| `views/`      | 视图逻辑 (settings/navigation)        |
| `utils/`      | 工具函数 (dom/theme/registry-helpers) |
| `constants/`  | 常量 (i18n 翻译)                      |

## views/ 模块

| 文件             | 职责                             |
| ---------------- | -------------------------------- |
| `settings.ts`    | 设置页主逻辑                     |
| `registry-ui.ts` | 站点注册表 UI (标签页/搜索/列表) |
| `navigation.ts`  | 视图切换                         |
| `i18n-apply.ts`  | 语言应用                         |

## 约束

- 每次打开都是新实例
- 及时清理 requestAnimationFrame
