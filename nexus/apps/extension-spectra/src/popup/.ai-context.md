# Popup UI

**用途**：用户主界面 (音量/EQ/可视化/设置)

## 文件索引

| 文件       | 职责     |
| ---------- | -------- |
| `index.ts` | 入口     |
| `types.ts` | 类型定义 |

## 子目录

| 目录          | 职责                                  |
| ------------- | ------------------------------------- |
| `card/`       | 标签页卡片 (init/render/events)       |
| `visualizer/` | 频谱可视化                            |
| `views/`      | 视图逻辑 (settings/navigation)        |
| `utils/`      | 工具函数 (dom/theme/registry-helpers) |
| `constants/`  | 常量 (i18n 翻译)                      |

## registry-helpers

处理 `DomainEntry[]` 数据：

- `migrateRegistry()` - 旧格式迁移
- `formatEntry()` - 显示格式化 (🔍 标记来源)
- `parseEntry()` - 用户输入解析

## 约束

- 每次打开都是新实例
- 及时清理 requestAnimationFrame
