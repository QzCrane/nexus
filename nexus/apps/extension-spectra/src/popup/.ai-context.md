# Popup UI

**用途**: 扩展用户交互界面 (音量/EQ/频谱/设置/视频控制)。

## 目录

- card/: 标签页卡片 (初始化/渲染/事件/保存预设)
- visualizer/: 频谱循环绘制
- views/: 设置页 + 注册表 + 预设管理 UI
- side-panel/: 侧边栏 (Audio/Speed/EQ/Video 控件)

## 关键模块

- video-controls.ts: 全屏/跳转/滤镜/AB 循环按钮绑定
- presets-ui.ts: 域名预设查看/删除
- i18n-apply.ts: 全局 data-i18n / data-i18n-title / data-i18n-placeholder 应用

## 国际化 (I18N)

- 机制: 默认 en-US, 存储于 globalSettings.lang
- 扩展: 同时更新 `types/i18n.types.ts` 和 `constants/i18n/` 下所有语言
- 响应: settings.ts 负责在保存时广播并触发 `updateRegistryI18n` 等实时渲染更新
- 兼容: 支持 [data-i18n-placeholder] 本地化搜索框

## 约束

- 每次打开为全新实例，关闭前须清理 rAF
- UI 同步须依赖 UI_SYNC 消息
