# Remote 遥控模块

**用途**: 手机扫码 → WebRTC P2P → 遥控 PC 端媒体

## 文件 (Popup 端)

| 文件            | 职责                  |
| --------------- | --------------------- |
| qr-generator.ts | QR 码生成 (qrcode 库) |
| ui-bindings.ts  | 弹窗 UI, 高度调整     |

## 文件 (Background 端)

| 文件                          | 职责                      |
| ----------------------------- | ------------------------- |
| background/remote-service.ts  | Offscreen 生命周期管理    |
| background/remote-commands.ts | 命令执行 (发送到 Content) |
| offscreen-remote/index.ts     | PeerJS 运行 (WebRTC)      |
| public/remote.html            | 手机遥控器 H5 页面        |

## 架构

```text
[Popup] → sendMessage → [Background]
                            ↓ ensureOffscreen
                     [Offscreen Document]
                            ↓ PeerJS
                     [手机 remote.html]
                            ↓ DataChannel
                     [Offscreen] → sendMessage
                            ↓
                     [Background] → tabs.sendMessage
                            ↓
                     [Content Script 执行]
```
