# Remote 遥控模块

**用途**: 手机扫码 → WebRTC P2P → 遥控 PC 端媒体

## 文件

| 文件               | 职责                  |
| ------------------ | --------------------- |
| qr-generator.ts    | QR 码生成 (qrcode 库) |
| session.ts         | 会话 ID + storage     |
| peer-connection.ts | PeerJS WebRTC 连接    |
| ui-bindings.ts     | 弹窗 UI + 命令路由    |
| remote.html        | 手机遥控器 H5 页面    |

## 架构

```text
Popup(initPeer) → PeerJS Cloud → remote.html(connect)
       ↑ DataChannel(cmd) ←────────────┘
       ↓
  tabs.sendMessage → Content执行
```

## 部署

- 本地: `chrome-extension://xxx/remote.html`
- 托管: `spectra-remote.pages.dev` (可选)
