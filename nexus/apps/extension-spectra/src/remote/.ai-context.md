# Remote 遥控模块

**用途**: 手机扫码 → WebRTC P2P → 遥控 PC 端媒体

## 文件 (Popup 端): 职责

qr-generator.ts: QR 码生成 (qrcode 库)
ui-bindings.ts: 弹窗 UI, 高度调整

## 文件 (Background 端): 职责

remote-service.ts: Offscreen 生命周期管理
remote-commands.ts: 命令执行 + 状态同步
offscreen-remote/index.ts: PeerJS 运行 (WebRTC)
remote-site/index.html: 手机遥控器 H5 (Cloudflare 托管)

## 状态同步 (RemoteState)

- volume/muted/playing/speed: 音频+媒体状态
- tabTitle/tabDomain: 标签页信息 (v1.1+)

## 架构

```text
[Popup] → sendMessage → [Background]
                            ↓ ensureOffscreen
                     [Offscreen Document]
                            ↓ PeerJS
                     [手机 remote-site]
                            ↓ DataChannel
                     [Offscreen] → sendMessage
                            ↓
                     [Background] → tabs.sendMessage
                            ↓
                     [Content Script 执行]
```

## 托管

- 公网: `nexus-remote.pages.dev` (Cloudflare Pages)
- 源码: `/remote-site/index.html` (独立目录)
