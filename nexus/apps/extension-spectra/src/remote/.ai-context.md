# Remote 遥控模块

**用途**: 手机扫码 → WebRTC P2P → 遥控 PC 端媒体

## 文件 (Popup 端): 职责

- qr-generator.ts: QR 码生成 (qrcode 库)
- ui-bindings.ts: 弹窗 UI, 连接状态检查, i18n 绑定
- modal-renderer.ts: 遥控弹窗 DOM + 多语言渲染

## 文件 (Background 端): 职责

- remote-service.ts: Offscreen 生命周期管理
- remote-commands.ts: 命令执行 + 状态同步 (tabId)
- offscreen-remote/index.ts: 多会话 PeerJS (WebRTC)
- remote-site/index.html: 手机遥控器 H5

## 多会话设计

- 每个标签页独立 session，通过 tabId 区分
- `sessions: Map<tabId, RemoteSession>` 存储
- 不同标签页可同时开启遥控器，互不干扰

## 多语言支持

- i18n 键: `remoteModalTitle`, `remoteSessionCode`, `remoteConnected`, `remoteWaiting`, `remoteHint`, `remoteDisconnect`, `remoteCopied`, `remoteOpenLinkTitle`, `remoteConnectedTooltip`
- 已支持: en/zh-CN/ja/ko/fr/de/es/ru

## 状态同步 (RemoteState)

- volume/muted/playing/speed: 音频+媒体状态
- tabTitle/tabDomain/tabFavIcon: 标签页信息

## 架构

```text
[Popup] → bindRemoteUI(tabId, dict) → 按钮连接状态检查
              ↓ 点击
       REMOTE_CREATE_SESSION(tabId)
              ↓
       [Background] → ensureOffscreen
              ↓
       [Offscreen] → sessions.set(tabId, session)
              ↓ PeerJS
       [手机 remote-site] → DataChannel
              ↓ 命令/状态
       [Background] → tabs.sendMessage(tabId)
              ↓
       [Content Script 执行]
```
