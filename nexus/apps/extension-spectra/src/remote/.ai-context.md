# Remote 遥控模块

**用途**: 手机扫码遥控 PC 端媒体播放

## 目录

- qr-generator.ts: QR 码生成 (qrcode 库)
- session.ts: 会话 ID 管理 + storage 持久化
- peer-connection.ts: PeerJS WebRTC P2P 连接
- ui-bindings.ts: 弹窗 UI + 命令处理

## 流程

1. 用户点击遥控按钮 → 创建会话 + 初始化 Peer
2. 生成 QR 码 (指向 remote.html?s=会话码)
3. 手机扫码打开遥控页面
4. 遥控页面通过 PeerJS 连接扩展
5. P2P DataChannel 传输命令

## 部署

- 本地: chrome-extension://xxx/remote.html
- 托管: spectra-remote.pages.dev (可选)
