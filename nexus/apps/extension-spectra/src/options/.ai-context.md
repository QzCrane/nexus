# Options 页

**用途**: 快捷键配置 + 国际化 (Chrome Slots + 网站独立)

## 模块

- index.ts: 入口
- theme.ts: 主题切换
- i18n.ts + i18n-dict.ts: 国际化 (9 语言)
- i18n-actions.ts + i18n-actions/\*: Action 名称翻译 (8 语言)
- slots-editor.ts: Chrome Command Slot 配置
- site-editor.ts: 网站独立配置
- modal.ts: 绑定编辑弹窗
- formatters.ts: 按键/参数格式化

## Chrome Command Slots

| 类型   | 数量 | 默认键      |
| ------ | ---- | ----------- |
| 预设   | 4    | Alt+↑/↓/M/S |
| 自定义 | 16   | 用户自设    |

## 扩展国际化

- `_locales/`: 9 语言 (en, zh_CN, zh_TW, ja, ko, es, fr, de, ru)
- manifest 使用 `__MSG_extName__` 引用

## 商店素材

- `store-listings/`: 各语言商店详细描述
