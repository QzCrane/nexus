# HALO - Chrome Web Store (English)

## Name

HALO - Local Utility SidePanel

## Summary (maximum 132 characters)

Local-first SidePanel tools for page inspection, text and data work, browser management, and explicit network tasks.

## Detailed description

HALO brings everyday browser, developer, text, data, and page utilities into one Chrome SidePanel. Most processing and persistence stay on your device, and HALO has no advertising, analytics, or telemetry.

### Local utilities

- Format, transform, inspect, compare, encode, hash, and generate text or structured data.
- Work with QR codes, colors, images, PDFs, page outlines, screenshots, notes, tasks, snippets, timers, and other focused tools.
- Keep tool state in local Chrome extension storage; selected preferences can use Chrome sync.

### Page and browser tools

- Inspect the active page, headers, fonts, technologies, media, storage, and document structure when the page and browser allow it.
- Use optional permissions for page archives, clipboard history, downloads, history, bookmarks, tab groups, user scripts, and extension management.
- Enable smooth page scrolling while preserving keyboard ownership for video and other media controls after direct player interaction.

### Explicit network tools

Network features run only when you invoke or enable them. API Tester sends the request you configure to the public endpoint you choose. IP Lookup uses ipinfo.io and may use api.ipify.org. Translation links open the selected provider. Favicons use Google's favicon service. Hover Zoom and dark mode may request page resources or supported site APIs. User-script installation fetches only the URL you provide.

The destination services receive ordinary network metadata and the fields needed for that operation. See the privacy policy for exact data flows, local retention, and provider details.

### Boundaries

Availability depends on the page, Chrome support, user activation, permissions, CORS, authentication, and site behavior. Chrome internal pages, protected content, and restricted frames may not be accessible. HALO does not bypass browser security or promise identical behavior on every website.

HALO's own executable code is bundled in the submitted package. User-authored or imported scripts are a separate opt-in capability executed through Chrome's `userScripts` permission and user-selected match rules.
