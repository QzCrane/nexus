# HALO 上下文

## 身份

名称: HALO | 角色: 万能工具箱 | 形式: SidePanel-only (图标/右键菜单入口)

核心: 零上传/零追踪/零成本 | 定位: 通用用户+开发者

## 架构

类型: MV3 扩展 | 栈: React 18 / Esbuild

存储: chrome.storage.local/sync (kernel wrapper)

UI: @nexus/ui-kit + CSS Variables 主题系统

## 入口方式

1. 扩展图标点击 → 直接打开 SidePanel
2. 页面右键菜单 → "Open HALO Toolbox"
3. 选中文本右键 → "Generate QR Code"

## 依赖

@nexus/contracts | @nexus/kernel | @nexus/ui-kit | qrcode^1.5

## 路径

```text
entry/: background.ts / content.ts / sidepanel.tsx
kernel/: types.ts / storage.ts / settings.ts / theme.ts
tools/: qrcode/ color-picker/ json-formatter/ ruler/ outline/ settings/
modules/: dark-mode/(⏸️) [🔜 pdf/ archive/]
```

## 工具模块 (直接集成)

| ID             | 状态 | 说明                          |
| :------------- | :--: | :---------------------------- |
| qrcode         |  ✅  | 二维码生成 + 历史 + 右键集成  |
| color-picker   |  ✅  | HEX/RGB/HSL + 历史            |
| ruler          |  ✅  | 页面拖拽测量 px/rem           |
| json-formatter |  ✅  | 格式化/压缩/排序键            |
| outline        |  ✅  | 页面大纲 + 点击跳转 + MD 导出 |
| settings       |  ✅  | 主题/强调色/UI 偏好           |
| clipboard      |  🔜  | 智能剪贴板                    |

## 主题系统

支持: Dark/Light/System 三模式
强调色: 7 种预设 (Purple/Blue/Cyan/Green/Orange/Pink/Red)
CSS Variables: --halo-bg, --halo-text, --halo-accent, etc.

## 消息类型

HALO_GET_STATUS / HALO_TOOL_ACTIVATE
HALO_RULER_START/CANCEL/RESULT
HALO_SCROLL_TO_HEADING

## 存储键

HALO_SETTINGS: { theme, accentColor, compactMode, ... } (sync)
HALO_QRCODE_HISTORY / HALO_COLOR_HISTORY (local)
HALO_JSON_OPTIONS / HALO_RULER_SETTINGS / HALO_OUTLINE_SETTINGS (local)
