# Halo 语境

## §1 架构 (v2.7)

DNA: SidePanel | 零上传 | 原子化 | 本地优先 | 性能极致
结构: `src/{entry,components/{manager,search,core,settings},kernel,tools,scripts,system,i18n}`
插件: Tool`tools/` | Script`scripts/`(SaaT) | System`system/`
分类: Active → Scripts → System → {Gen,Enc,Fmt,Net,Dat,Dev,Eff,Bro,Vis,Med,Sec,AI}
核心: UniSearch(拼音/模糊) | State(原子/禁监听/实时同步) | Perm(声明式) | SaaT(脚本容器)
多语言: Flat`tools.id` → AutoAgg(`gen-registry`) → RuntimeNest(Hydrate) → 解决冲突/扁平开发
HoverZoom: RuleEngine(子域名匹配) | SiteRule(函数式/声明式) | MSE(DASH 流式增量加载/2MB 首批) | 动态分辨率(viewport→ 720/1080P) | B 站 Referer 代理
SaaS Modules:

- Bilibili+: Clean Home | Playback Speed | Esc Fix | Highest Quality
- LLM Enhancer: Multi-Platform(GPT/DS/Gemini) | Timeline V3 (TS/Event-Driven) | Widescreen | Keep Alive

## §2 规则

硬限: 源码 ≤200 行 | 文件>150(警) | 结构`module/{core,panel,index}` | 索引 ≤50
流程: Contracts ← Kernel ← {Audio,UI} ← Halo
规范: 禁 Tailwind | 预检路径/行数 | 逻辑分离(Core/UI) | 必须 SSOT | Hot Path 必须零分配 | 全棧 Bun

## §3 调研 (行业痛点 → Halo 方案)

DarkReader: 延迟 500ms/高 CPU/白屏闪烁/破站 → CSS 滤镜(<50ms)/无 JS 轮询/启动注入/静态白名单
OneTab: 崩溃丢数据(2M+受害)/无云同步/转付费 → IDB+Drive 双备份/跨端同步/模糊搜/原位打开
Lightshot: URL 可遍历泄露/强制上传/无加密 → 100%本地处理/WASM-OCR/隐私标注/HTML 预览
QR: 隐私追踪/恶意链接/权限滥用 → 离线生成/URL 安全预览/最小权限(ActiveTab)/本地历史
Scroll: 油管卡顿/资源高耗/虚拟滚动失效 → CSS 属性优先/Overscroll 阻断/捕获阶段接管(Douyin)/视频页跳过/SidePanel 键盘支持/ZeroAlloc 引擎/Spring 极速算法
Clip: 明文存密码/恶意篡改/历史泄露 → 敏感词脱敏/AES 加密/只读模式/无限本地历史
Limit: 更改时间绕过/隐私模式失效 → 时间服务器校验/挑战锁/跨浏览器同步/羞耻统计

## §4 缺口 (全网竞品对标)

JSON: Tree 视图(折叠) | JSONPath 查询 | 转 CSV/YAML/XML | 文件拖入 | Diff 对比 | 错误行高亮
Hash: HMAC(带密钥) | SHA-3 系列 | 哈希验证比对 | CRC32 | 批量文件计算
QR: Logo/图片嵌入 | 自定义前背景色 | 批量生成 | SVG 矢量导出 | vCard/WiFi 模板
Color: WCAG 对比度检查 | 渐变生成 | 颜色历史 | 网页吸管(Picker)
B64: 图片直接预览 | DataURI MIME 解析 | 结果转文件下载
Time: 多时区列表 | 日期计算(工时) | 自定义格式(strftime)
Pwd: 强度指示条 | 易读模式(单词) | 排除相似符(1/l)
URL: Query 参数构建器 | URL 规范校验 | 格式化
Reg: 正则解释(图解) | 多语言风格(Go/Py) | 常用库插入
UUID: v5(命名空间) | 批量生成 | GUID 格式
