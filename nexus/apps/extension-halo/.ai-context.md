# HALO 上下文

## 身份

名称: HALO | 角色: 万能工具箱 | 形式: Side Panel
核心: 零上传/零追踪/零成本 | 定位: 通用用户+开发者

## 架构

类型: MV3 扩展 | 栈: React 18 / Esbuild
存储: chrome.storage.sync (Kernel wrapper)
UI: @nexus/ui-kit (Toggle/Card) + Side Panel

## 依赖

@nexus/contracts | @nexus/kernel | @nexus/ui-kit | darkreader(⏸️)

## 功能模块

### 通用工具 (W2-W4)

- 二维码生成/识别
- 颜色拾取器
- JSON 格式化
- 页面大纲
- 尺子/测量

### 效率工具 (W5-W8)

- 标签分组 + AI 搜索
- 截图 + 本地批注
- 剪贴板历史
- 阅读模式

### AI 工具包 (W8+)

- 听歌识曲 (ACRCloud)
- AI 摘要 (本地 ONNX)
- OCR

### 搁置

- 深色模式 (darkreader CSP 兼容问题)

## 路径

entry/: background.ts / content.ts / popup.tsx
kernel/: storage.ts
modules/: dark-mode.ts(⏸️) / dark-mode-panel.tsx(⏸️)
tools/: [待建] qrcode/ color-picker/ json-formatter/

## 消息

HALO_DARK_MODE_TOGGLE: { payload: boolean } -> 切换深色
HALO_WHITELIST_CHANGED: {} -> 重新检查白名单
HALO_GET_STATUS: {} -> { hostname, darkModeActive }
