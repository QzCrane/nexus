# HALO 上下文 (v2.6.5)

形态: SidePanel | 核心: 零追踪/本地优先 | 定位: 取代 He3 的浏览器套件

## 🏗️ 架构概要

Auto-Registry: manifest.json+locales → generate-registry → \_generated.ts
Tree: src/{entry, components, kernel, tools, system, i18n}
SaaT: toolType:'script' → saat-service.ts → userScripts engine

## 🛠️ 工具箱 (✅ 90 tools)

Core: qrcode, color-picker, json-formatter, hash, uuid, timestamp, url, store, settings...
Dev: regex, userscripts(Pro), yaml, diff, csv-viewer, ip, jwt, sql, protobuf, dom, api-tester...
Efficiency: smooth-scroll(v2), tabs, pdf, clipboard, pomodoro, chatgpt-wide(SaaT)...
Other: password-gen, totp, image-tools, cookie, reader, translate, tab-group, bilibili-plus(SaaT)...

## 🔌 核心服务

- Search: unified-search.ts (Pinyin/多字段) | State: useToolState (Atomic/Sync)
- Permissions: PermissionManager | SaaT: saatDispatcher (Centralized script orchestration)
- Quality: Playwright + safe-storage (100% Coverage/Timeout Protection)
- Performance: EngineStatusProvider | Visibility Pause | RedLine: 禁轮询/资源未 detach
- ResourceMonitor: SSOT 全监控 (11 种 CPU 机制分类/来源标注)

## 🔒 红线

- Msg: HALO*TOOL_ACTIVATE | HALO_RULER*\* | HALO_CLIPBOARD_ADD
- 强: 消费 EngineStatusProvider | 函数 ≤150 行/源码 ≤200 行 | 定时器带 visibility 暂停
- 禁: 独立 Storage 监听 | 动态 Padding | **必须用 SafeStorage 代理 chrome.storage**
- 类型: ToolMeta 统一 (去 Module 术语) | i18n: tools/{id}/locales/ (Flat Source)

## 🎭 Overlay & UI 规范

所有浮层禁 position:fixed，必用 `useOverlay()` from `components/ui`
提供: showModal, showToast({message,type}), showLoading, showSheet
UI Kit: SearchInput (Ctrl+K), Card, Toggle, Button from @nexus/ui-kit

## ⚡ 后台消耗注册 (manifest.json field: background)

Mechanism: interval_slow/fast, raf_active/idle, _\_listener, mutation_observer...
Fields: frequency(真实频率), activeOnly, level(high/mid/low), sourceFile/Line/Detail
Scenario: setInterval, RAF, MutationObserver, chrome._.onChanged...
