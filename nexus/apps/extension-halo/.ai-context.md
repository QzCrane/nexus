# HALO 上下文

## 身份

名称: HALO | 角色: 效能/美学扩展 | 核心: 零上传/零追踪/零成本

## 架构

类型: MV3 扩展 | 栈: React 18 / Esbuild
存储: chrome.storage.sync (Kernel wrapper)
UI: @nexus/ui-kit (Toggle/Card)

## 依赖

@nexus/contracts | @nexus/kernel | @nexus/ui-kit | darkreader

## 功能

深色模式: ⏸️ 搁置 (darkreader CSP 兼容问题)

- modules/dark-mode.ts (darkreader 封装)
- modules/dark-mode-panel.tsx (UI 控制面板)
- 白名单: storage.ts (hostname 级别)

二维码: ❌ 规划中
平滑滚动: ❌ 规划中
截图: ❌ 规划中

## 路径

entry/: background.ts / content.ts / popup.tsx
kernel/: storage.ts (HALO 存储)
modules/: dark-mode.ts / dark-mode-panel.tsx

## 消息

HALO_DARK_MODE_TOGGLE: { payload: boolean } -> 切换深色
HALO_WHITELIST_CHANGED: {} -> 重新检查白名单
HALO_GET_STATUS: {} -> { hostname, darkModeActive }
