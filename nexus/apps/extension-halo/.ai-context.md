# HALO 上下文

## 身份

名称: HALO | 角色: 万能工具箱 | 形式: SidePanel-only

核心: 零上传/零追踪/本地优先 | 定位: 取代 He3 的浏览器原生终极开发者套件

## 核心壁垒 (Competitive Moat)

- **形态壁垒 (Form Factor)**: SidePanel 侧边栏常驻，即用即走，解决 Popup 易关、Content Script 污染 DOM、Desktop App 割裂感痛点。
- **隐私壁垒 (Privacy First)**: 严格执行 "Local First"。本地能处理的绝不上传 (pdf-lib, ffmpeg-wasm)。云端服务 (OCR) 采用 "显式授权 + 动态提权" 机制，拒绝静默请求。
- **聚合壁垒 (All-in-One)**: 解决 "插件地狱"。打通工具间数据流 (e.g. 截图 -> OCR -> JSON -> 格式化)，统一 UI/交互/快捷键。
- **生态壁垒 (Browser Landscape)**:
  - Chrome: 填补官方侧边栏工具箱的真空 (Google 仅提供书签/历史)。
  - Edge: 提供比官方 Sidebar 更硬核的 "开发者级" 替代品 (vs Edge Tools)。

## 生态策略 (Ecosystem)

- **定位**: "Browser-native Developer Utility Suite" (非单一功能，而是工具套件)。
- **合规 (Store Policy)**: 以 "Developer Toolbox" 为伞状目的 (Umbrella Purpose)，规避 "Single Purpose" 限制。
- **扩展管理**: 不做插件容器，而是做 "Native Extension Manager" (SidePanel 管理器)，提供分组、快捷键功能。

## 技术策略 (Tech Strategy)

- **Hybrid Engine**:
  - **Local Core**: 小体积 JS/WASM，处理 90% 需求 (PDF Merge, Img Trans)。
  - **Cloud Pool**: 适配器模式接入多源 API，解决 10% 重型需求 (OCR, Office)。
- **Lazy Load**:
  - **Code**: 路由级动态导入，降低启动内存。
  - **Resource**: 大模型/WASM 采用 `Resources Manager` 按需下载 + Hash 校验 + IndexedDB 缓存。
- **权限管理**:
  - 核心权限 (`sidePanel`, `storage`) 安装时申请。
  - 敏感权限 (`scripting`, `downloads`) 使用时动态申请 (Optional Permissions)。

## 架构

类型: MV3 扩展 | 栈: React 18 / Esbuild / i18n (中/英)

UI: @nexus/ui-kit + CSS Variables 主题 + 微动画
Layout: Dual Mode (Classic/Launcher) + Adaptive Response

Tree: `src/{entry, components, tools, kernel, assets}`
