## 🎭 Overlay 统一系统 (v2.6.4)

**所有浮层必须通过统一 API 调用，禁止自建 position: fixed 元素！**

```tsx
import { useOverlay } from "../../components/ui/overlay";
const {
  showModal,
  showToast,
  showLoading,
  showSheet,
  hideLoading,
  closeSheet,
} = useOverlay();
```

| API             | 用途                | 参数                                                       |
| --------------- | ------------------- | ---------------------------------------------------------- |
| `showModal()`   | 确认/警告弹窗       | `{title, message, type:'confirm'\|'danger', onConfirm}`    |
| `showToast()`   | 轻量提示 (自动消失) | `{message, type:'success'\|'error'\|'warning', duration?}` |
| `showLoading()` | 全屏加载            | `{message?, spinner?}`                                     |
| `showSheet()`   | 底部抽屉            | `{title?, content, height:'auto'\|'half'\|'full'}`         |

## 🎨 UI 组件统一规范 (v2.6.4)

**禁止工具自建 UI 组件！必须使用统一 UI Kit：**

```tsx
import { useOverlay, SearchInput } from "../../components/ui";
```

| 组件           | 用途      | 说明                                   |
| -------------- | --------- | -------------------------------------- |
| `SearchInput`  | 搜索框    | 与主页搜索样式一致，支持 Ctrl+K 快捷键 |
| `useOverlay()` | 弹窗/提示 | Modal/Toast/Loading/Sheet              |
| `Card`         | 卡片容器  | 来自 `@nexus/ui-kit`                   |
| `Toggle`       | 开关      | 来自 `@nexus/ui-kit`                   |
| `Button`       | 按钮      | 来自 `@nexus/ui-kit`                   |

**禁止自建**: searchInput 样式、toast 样式、modal 样式、固定定位浮层

## ⚡ 后台消耗注册 (MUST)

**任何后台 CPU 消耗都必须在 manifest.json 中声明 `background` 字段！**

```json
"background": {
  "mechanism": "interval_slow",  // interval_fast/slow, raf_active/idle, *_listener, mutation_observer...
  "frequency": "1000ms",         // 来自代码的真实频率 (UI 显示: 定时器 1000ms)
  "activeOnly": true,            // 是否仅面板打开时运行
  "level": "medium",             // high/medium/low/idle
  "sourceFile": "tools/xxx/panel.tsx",
  "sourceLine": 42,
  "sourceDetail": "setInterval(() => {...}, 1000)"
}
```

**触发场景**: setInterval, requestAnimationFrame, MutationObserver, chrome.\*.onChanged, addEventListener 等
**不需要注册**: setTimeout (一次性)、事件触发型回调 (无持续消耗)
