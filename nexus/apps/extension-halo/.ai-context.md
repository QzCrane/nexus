# HALO 上下文 (v2.3.0)

形态: SidePanel | 核心: 零追踪/本地优先 | 定位: 取代 He3 的浏览器原生开发套件

## 🏗️ 架构概要 (详细见 docs/architecture.md)

Auto-Registry: manifest.json → generate-registry → \_generated.ts & loader.ts & i18n
Tree: src/{entry, components(sidepanel/Context), kernel(utils/unified-search/managers), tools, system(settings/store/perms), i18n(aggregator)}

## 🛠️ 工具箱 (✅ 85 tools: 82 User + 3 System)

Core: qrcode, color-picker, json-formatter, hash, uuid, timestamp, url, store, settings, permissions...
Dev: regex, **userscripts(Pro:chrome.userScripts API/Edit/Exclude/Header/ImpExp/Templates)**, yaml, diff, csv-viewer, ip, jwt, sql, protobuf, dom, api-tester...
Efficiency: smooth-scroll(v2), tabs, pdf, clipboard(intent), pomodoro, session...
Security/Media/Browser: password-gen, totp, image-tools, cookie, reader, translate, tab-group...

## 🔌 核心服务 (v2.2.0)

- Search: unified-search.ts (全语言+Pinyin+多字段+动态扩展)
- State: `useToolState` (Atomic/Sync/Debounce/Intent) | SidePanelContext
- Permissions: `PermissionManager` (Kernel) + `system/permissions`
- Quality: Playwright (UI Test) + safe-storage (Timeout Protection)
- Performance: EngineStatusProvider | detachNode | Zero-Copy
