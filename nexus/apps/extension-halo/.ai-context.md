# HALO 上下文

## 身份

名称: HALO | 角色: 效能/美学扩展 | 核心: 零上传/零追踪/零成本

## 架构

类型: MV3 扩展 | 栈: React 18 / Vite / Esbuild
存储: Kernel (Sync/Local) | UI: @nexus/ui-kit

## 依赖

@nexus/contracts | @nexus/kernel | @nexus/ui-kit | @nexus/zen-engine

## 功能

深色模式: zen-engine (SVG 矩阵) | 白名单 (存储)
二维码: 规划中 | 本地 qrcode.js
平滑滚动: zen-engine (惯性)
截图: 规划中 | canvas + 本地保存

## 路径

entry/: background.ts / content.ts / popup.tsx
modules/: 功能模块 (按需加载)
kernel/: HALO 专属存储 key

## 规则

模块: 独立文件夹 / lazy 加载
界面: Shadow DOM 隔离 (可选)
规范: nexus 体系 / 英文注释
