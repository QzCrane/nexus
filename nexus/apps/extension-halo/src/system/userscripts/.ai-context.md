# UserScripts 模块上下文

## 架构 (v2.3.0)

**注入机制**: `chrome.userScripts` API (Chrome 120+) → 真正的 `document_start` MAIN world 注入

## 文件结构

- `types.ts`: UserScript/State 类型定义
- `core.ts`: CRUD/Import/Export/Templates/URL 匹配
- `registry.ts`: 动态注册 (`chrome.userScripts.register`) + storage 监听
- `engine.ts`: 消息监听 (runCount/sync) + 手动注入
- `panel.tsx`/`panel-parts.tsx`: UI 组件
- `panel.styles.ts`: 样式定义
- `locales/`: i18n (en/zh)

## 关键功能

1. **document_start 注入**: 脚本在页面脚本之前执行
2. **MAIN world**: 直接操作页面 DOM/JS，非 isolated world
3. **Templates**: Block Space Scroll (手动视频控制), Dark Mode, Ad Block...
4. **权限**: `userScripts` (optional) + `*://*/*` (hosts)

## 红线

- 禁止在 content.ts 中异步读取 storage 后注入 (太晚)
- 必须使用 `chrome.userScripts.register` 动态注册
- Block Space: 必须同时 `preventDefault` + `stopImmediatePropagation` + 手动 `video.play()/pause()`
