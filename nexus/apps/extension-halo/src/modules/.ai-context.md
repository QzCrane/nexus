# 模块上下文

## 模式

结构: index.ts(接口) / ui.tsx(界面) / logic.ts(逻辑) / styles.css(隔离样式)

## kernel/

storage.ts: 存储 key 定义 + 白名单管理 API

- STORAGE_KEYS: DARK_MODE_ENABLED, DARK_MODE_WHITELIST
- isHostnameWhitelisted / addToWhitelist / removeFromWhitelist

## 功能列表

深色 (`@nexus/zen-engine`): SVG 矩阵反转 | 白名单排除 | <50ms 目标
二维码 (`qr-code/`): 规划中 | 技术: qrcode.js (本地) | 权限: activeTab
标签页 (`sidebar-tabs/`): 规划中 | 技术: chrome.tabs | UI: 侧边栏
截图 (`screenshot/`): 规划中 | 技术: canvas + 本地保存
