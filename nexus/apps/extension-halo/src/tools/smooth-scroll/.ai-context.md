# Smooth Scroll 模块上下文

## 职责

平滑滚动功能 | 网页/SidePanel 双端 | 队列引擎防跳动

## 文件结构

| 文件        | 职责              | 行数 |
| ----------- | ----------------- | ---- |
| `engine.ts` | 队列+差分滚动引擎 | 148  |
| `utils.ts`  | 目标查找+缓存     | 72   |
| `types.ts`  | 类型+默认值+预设  | 58   |
| `panel.tsx` | 设置 UI           | ~240 |
| `core.ts`   | 存储操作          | ~30  |

## 核心机制 (基于 gblazex/smoothscroll)

**队列系统**: 滚动命令入队 `que.push()` → 单 `requestAnimationFrame` 循环 → 防多动画冲突

**差分计算**: `delta = item.x * position - item.lastX` → 每帧只滚增量 → 避免绝对位置跳动

**方向检测**: `directionCheck()` 检测 x/y 符号变化 → 清空队列 → 防反向跳动

**目标缓存**: `WeakMap<Element, target>` → 1 秒后清空 → 减少 DOM 遍历

## Easing 选项

| 名称       | 公式        | 特点                      |
| ---------- | ----------- | ------------------------- |
| `spring`   | `1-(1-t)^4` | 四次方 ease-out, 最快响应 |
| `ease-out` | `1-(1-t)^3` | 三次方, 标准减速          |
| `ease`     | 二次 In-Out | 先加速后减速              |
| `linear`   | `t`         | 匀速                      |

## 参数

stepSize | animationTime | accelerationMax | accelerationDelta | arrowKeyStep | easing

## 存储键

- `HALO_SMOOTH_SCROLL_SETTINGS` - 当前设置
- `HALO_SMOOTH_SCROLL_CUSTOM` - 用户自定义预设

## 入口

- `content/smooth-scroll.ts` - 网页注入 (wheel/keyboard/middle-click)
- `entry/sidepanel-init.ts` - SidePanel 滚动 (wheel only)
