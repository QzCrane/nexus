# PDF Module Context

## 身份

名称: PDF Toolbox | 角色: 混合架构 PDF 处理器 | 状态: **v0.2.0 ✅**

## 架构 (Hybrid Engine)

- **Local Core**: pdf-lib (Merge/Split/Extract/Rotate/Watermark/ImagesToPDF)
- **Lazy Load**: React.lazy 动态导入 + ResourceManager 缓存
- **Cloud Pool**: 预留 (OCR/Office 适配器模式)
