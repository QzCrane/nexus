# PDF Module Context

## 身份

名称: PDF Toolbox | 角色: 混合架构 PDF 处理器 | 状态: Alpha

## 架构 (Hybrid Engine)

- **Local Core (pdf-lib)**:
  - 场景: 90% 高频轻量需求 (Merge/Split/Watermark)
  - 优势: 纯内存操作，秒级响应，零隐私风险 ($0 成本)
  - 实现: 纯前端 JS 处理 ArrayBuffer/Blob
- **Cloud Pool (API)**:
  - 场景: 10% 复杂需求 (Office 转 PDF/OCR/高保真编辑)
  - 策略: 适配器模式 (Adapter Pattern)，接入多源免费/付费 API
  - 交互: 必须显式标记 `☁️ 需联网`，禁止静默上传
- **懒加载架构 (Lazy Load)**:
  - Code Tier: 核心 JS 代码动态导入 (Dynamic Import)，减少启动内存。
  - Resource Tier: 大型模型/WASM 按需下载 + IndexedDB 缓存 + Hash 校验。

## 功能

- **Spline/Merge**: 简单拖拽排序 (Local)
- **Images <-> PDF**: 无损转换 (Local)
- **Watermark**: 文本/图片水印 (Local)
- **Office/OCR**: 暂留接口，等待 Pool 接入 (Cloud)
- **Context Menu**: 网页右键 "Open in Halo PDF Editor"
- **Drag & Drop**: PDF 文件直接拖入 SidePanel

## 开发策略

- **Phase 1**: Local Core 基础功能 (Merge/Split/Img) + 拖拽/右键交互。
- **Phase 2**: Cloud Pool 基础架构 + 懒加载资源管理器 (Resource Manager)。
- **Phase 3**: 高级功能接入。

## 依赖

- core: `pdf-lib` (Document/Page/Image manipulation)
- utils: `jszip` (Backup), `file-saver` (Download)
- ui: `@nexus/ui-kit` (DragList, FileUpload)
