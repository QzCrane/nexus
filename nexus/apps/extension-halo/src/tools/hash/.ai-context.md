# Hash 模块上下文

## 职责

哈希生成 | 文件校验

## 文件结构

| 文件        | 职责                  | 行数 |
| ----------- | --------------------- | ---- |
| `types.ts`  | 类型                  | 15   |
| `core.ts`   | 核心逻辑 (Web Crypto) | 40   |
| `panel.tsx` | UI                    | ~120 |
| `index.ts`  | 导出                  | 5    |

## 功能

- 支持算法: SHA-1, SHA-256, SHA-384, SHA-512
- 实时文本 Hash 计算
- 本地文件 Hash 计算 (MD5 暂不支持, 仅 SHA)
- 结果大写/复制

## 依赖

`crypto.subtle` (浏览器原生 API)
