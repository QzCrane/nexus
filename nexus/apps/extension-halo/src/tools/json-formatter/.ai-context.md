# JSON Context

## 身份

名称: JSON Formatter | 角色: JSON 格式化与校验 | 状态: Ready

## 功能

- **格式化**: Pretty print (2 spaces)
- **压缩**: Minify (remove whitespace)
- **排序**: Sort keys alphabetically
- **校验**: Valid JSON check

## 架构

- **Core**: `JSON.parse` / `JSON.stringify`
- **Error**: Detailed error messaging
