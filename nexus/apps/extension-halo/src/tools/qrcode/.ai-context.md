# QR Code Tool

## 身份

工具: qrcode | 功能: 二维码生成/识别 | 状态: ✅ Ready

## 文件

```text
types.ts   # QRCodeOptions, QRCodeState, constants
core.ts    # generateQRCode, history mgmt, download/copy
panel.tsx  # UI component
index.ts   # exports
```

## 依赖

qrcode^1.5 (bun)

## 功能

- 生成: text/URL → data URL (白字透明底)
- 历史: 最近 10 条 (FIFO, local storage)
- 操作: 复制到剪贴板 / 下载 PNG
- 快捷键: Ctrl+Enter 生成

## 存储

HALO_QRCODE_HISTORY: string[] (local)

## 规划 (🔜)

- 识别: 拖入图片/粘贴解码
- 批量: 多个文本生成
- 样式: 自定义颜色/Logo
