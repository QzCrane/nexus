# Screenshot Module Context

## 身份

名称: Screenshot | 角色: 截图与批注 | 状态: Beta

## 功能

- **可见区域**: `captureVisibleTab`
- **区域截图**: Crop UI 裁剪
- **批注**: 画笔/箭头/文字 (Canvas)
- **导出**: 下载 PNG / 复制到剪贴板

## 架构

- **Capture**: Chrome API (PNG)
- **Editor**: React Component with Canvas overlay
- **Flow**: Panel Click -> Capture -> Show Editor -> Save
