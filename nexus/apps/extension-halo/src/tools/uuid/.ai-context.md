# UUID 模块上下文

## 职责

唯一 ID 生成 | UUID v4/v7/ULID

## 文件结构

| 文件        | 职责                                         | 行数 |
| ----------- | -------------------------------------------- | ---- |
| `types.ts`  | 类型                                         | 15   |
| `core.ts`   | 核心逻辑 (v4/native, v7/custom, ULID/custom) | 70   |
| `panel.tsx` | UI                                           | ~90  |
| `index.ts`  | 导出                                         | 5    |

## 功能

- 支持版本: v4 (随机), v7 (时间序), ULID
- 批量生成 (最大 100 个)
- 格式选项: 大写, 连字符

## 依赖

`crypto.randomUUID`, `crypto.getRandomValues`
