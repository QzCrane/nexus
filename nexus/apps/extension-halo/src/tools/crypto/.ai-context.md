# Crypto 工具上下文

## 身份

加密工具箱: JWT/AES/RSA | 基于 jose 库

## 功能

- **JWT**: 解码/验证/创建 (HS256/384/512)
- **AES**: 密钥生成/加解密 (GCM-256)
- **RSA**: OAEP-2048 密钥对生成

## 架构

```
crypto/
├── index.ts    # 模块出口
├── types.ts    # 类型定义
├── core.ts     # 加密逻辑 (jose + Web Crypto API)
└── panel.tsx   # 三模式 UI (Tab 切换)
```

## 依赖

jose^6.x (JWT 验证/签名)

## 安全

密钥仅存内存 | 无网络传输 | 无持久化敏感数据
