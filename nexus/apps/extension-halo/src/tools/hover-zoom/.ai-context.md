## 数据流

```text
[mouseover] → detectQuick() → startTimer()
           → resolveEnhanced() → [site rule] or [image-resolver + hd-rules]
           → viewer.show(EnhancedResult)
           → [image: img.src] or [video: video.src]
```

## 触发模式 (hover-zoom.ts)

| 模式     | 行为                          |
| -------- | ----------------------------- |
| `hold`   | 按住快捷键显示，松开关闭      |
| `toggle` | 按一次显示，再按关闭/移出关闭 |

**依赖**: `mouseHasMoved` 标记确保鼠标至少移动一次才能按键触发

## 规则系统

**SiteRule**: `id` + `matches(host)` + `probe?` + `resolve(ctx)` → `ZoomResult`

**ResolveContext**: `{url, element, pageUrl, fetchWithProxy, getCookie}`

**ZoomResult**: `{type, sources[], audioUrl?, headers?, caption?}`

## 跨域代理

Content → `HALO_HZ_PROXY_AJAX` → Background fetch → Response

## B 站规则

| 场景     | URL 模式               | 数据源                                |
| -------- | ---------------------- | ------------------------------------- |
| 视频     | `/video/BVxxx`         | `__playinfo__` 或 `/x/player/playurl` |
| 番剧     | `/bangumi/play/epXXX`  | `/pgc/player/web/playurl`             |

## 布局算法 (layout.ts)

**四步骤设计** (原图尺寸优先):

1. **evaluateSpaces**: 评估四向空间 (Right/Left/Bottom/Top)
   - 水平方向: 高度=视口-边距 ×2
   - 垂直方向: 宽度=视口-边距 ×2
2. **checkOriginalFit**: 判断原图能否完整放入
3. **selectBestPosition**: 选择最佳位置
   - 能放入原图 → 直接选最佳方向 (按垂直空间排序)
   - 需缩放 → 选面积最大方向
4. **applyLayout**: 应用布局 + **边对齐** (浮图平行边覆盖源对应边)

**配置**:

- `scaleUpSmall: false` (保留待实现小图放大功能)
- `infoBarHeight: 36` (信息栏高度，布局自动预留)
- `marginBottom: 60` (底部边距，避开网站底部栏如 B 站推荐栏)

**视觉设计**: 2px 纯白边 + 底部信息栏 (外置，常显)

**⚠️ 强制约束**: 禁止拉伸变形！只允许等比缩放

- `calcSize`: 使用单一 scale 因子乘以宽高
- CSS: `object-fit: contain` (禁止 cover/fill)

## 性能优化 (2026-01-06)

| 优化项                | 技术               | 效果                        |
| --------------------- | ------------------ | --------------------------- |
| `isValidTrigger` 缓存 | WeakMap            | 避免重复 `getComputedStyle` |
| `bgImageCache`        | WeakMap            | 缓存背景图解析结果          |
| 图片预加载            | `preloadImage.src` | 提前加载到浏览器缓存        |
| 结果预加载            | `queueMicrotask`   | 悬停时异步预解析            |
| 缓存命中零延迟        | `preloadCache`     | 缓存结果直接显示            |
| 源元素 Loading        | Fixed overlay      | 解决父容器 overflow 问题    |

**数据流 (优化后)**:

```text
[mouseover] → isValidTrigger (cached) → preloadUrl → queueMicrotask(resolveEnhanced)
           → startTimer (delay or 0 if cached)
           → show (cached result or async resolve)
```

## DASH 视频处理

**现状**: B 站返回 `.m4s` 分离流，需要 MSE 合并才能播放

**临时方案**: 检测 DASH segment URL → fallback 到封面图

- `isDashSegment()`: 检测 `.m4s/.m4a` 扩展名
- `isPlayableVideoUrl()`: 验证可直接播放的格式
- `fallbackToThumbnail()`: 回退显示封面图

**长期方案**: 引入 `hls.js` 或 `shaka-player` 实现 MSE 合并
