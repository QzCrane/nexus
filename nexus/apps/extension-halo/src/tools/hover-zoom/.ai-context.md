# Hover Zoom AI Context

> update: 2026-01-06 | status: Refactor Complete

## 架构

遵循 **单一真理 (Single Resolver Type)** 原则，分离数据、逻辑与 UI。

```text
hover-zoom/
├── components/ui/       # 设置面板
├── logic/engine.ts      # DNR/Anti-hotlink
├── content/             # Content Script
│   ├── resolvers/       # URL 解析 (rule-resolver, image-resolver)
│   ├── utils/           # 工具 (proxy-utils, hotkeys, resource-key-helper)
│   ├── viewer/          # 浮层展示
│   │   ├── index.ts     # 控制器
│   │   ├── layout.ts    # 布局入口
│   │   ├── layout-types.ts/layout-calc.ts  # 布局类型/计算
│   │   ├── media-loader.ts  # 媒体加载工具
│   │   └── transform.ts # 交互
│   └── styles/          # 样式
├── rules/               # 规则库
│   ├── core.ts          # Resolver/RuleConfig/RuleEngine
│   └── definitions/     # 站点规则
└── types.ts             # 共享类型

# Content Entry (src/content/)
hover-zoom.ts            # 主入口 (精简)
hover-zoom-state.ts      # 状态管理
hover-zoom-events.ts     # 鼠标事件
hover-zoom-keys.ts       # 键盘事件
```

## 数据流

```
mouseover → hover-zoom.ts → rule-resolver.ts → RuleEngine/ImageResolver
                                   ↓
                          EnhancedResult
                                   ↓
                          viewer/index.ts → layout.ts
```

## 规则系统

核心思想：**RuleConfig as Syntax Sugar**. 运行时只有一种类型：函数。

**Resolver**: `(ctx) => Promise<string | Result | null>`
**Sugars**: `replace` | `selector` | `api`

## 布局算法

1. 评估四向空间
2. 原图能放入 → 选最佳方向
3. 否则 → 选最大空间并缩放
