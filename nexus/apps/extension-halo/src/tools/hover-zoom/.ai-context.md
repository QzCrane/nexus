# Hover Zoom AI Context

> update: 2026-01-06 | status: P0 prototype

## 架构

```
hover-zoom/
├── content/           # Content Script 模块
│   ├── rule-resolver.ts    # 增强解析器 (规则优先→通用回退)
│   ├── image-resolver.ts   # 基础图片URL解析
│   ├── hd-rules.ts         # 静态HD URL替换规则
│   ├── proxy-utils.ts      # CORS代理工具 (fetchWithProxy, getCookie)
│   ├── viewer.ts           # 浮层UI展示
│   ├── viewer-dom.ts       # DOM构建
│   ├── trigger-detector.ts # 触发检测
│   ├── hotkeys.ts          # 快捷键
│   └── styles*.ts          # 样式
├── rules/             # 站点规则系统
│   ├── types.ts       # SiteRule/ResolveContext/ZoomResult 接口
│   ├── registry.ts    # 规则注册器 (懒加载)
│   └── sites/         # 站点规则
│       └── bilibili.ts    # B站规则 (移植自HoverZoom+)
├── types.ts           # 设置类型
├── engine.ts          # 后台引擎 (anti-hotlink)
├── panel.tsx          # 设置面板
└── manifest.json      # 工具清单
```

## 规则系统

**SiteRule 接口**: `id` + `matches(host)` + `probe` (CSS) + `resolve(ctx)` → `ZoomResult`

**ResolveContext**: `{url, element, pageUrl, fetchWithProxy, getCookie}`

**ZoomResult**: `{type, sources[], audioUrl?, headers?}`

## 跨域代理

Content → `chrome.runtime.sendMessage({type:'HALO_HZ_PROXY_AJAX'})` → Background fetch → Response

## B 站规则覆盖

1. `/video/BVxxx` - 页面内嵌`__playinfo__` 或 API (`/x/player/playurl`)
2. `/bangumi/play/epXXX` - PGC API (`/pgc/player/web/playurl`)
3. `bilibili.tv/play/series/ep` - 国际站 API
4. `bilibili.tv/video/XXX` - 国际站视频

DASH 处理: video+audio 分离流 → 按 bandwidth 排序取最高
