## 数据流

```text
[mouseover] → detectQuick() → startTimer()
           → resolveEnhanced() → [site rule] or [image-resolver + hd-rules]
           → viewer.show(EnhancedResult)
           → [image: img.src] or [video: video.src]
```

## 触发模式 (hover-zoom.ts)

| 模式     | 行为                          |
| -------- | ----------------------------- |
| `hold`   | 按住快捷键显示，松开关闭      |
| `toggle` | 按一次显示，再按关闭/移出关闭 |

**依赖**: `mouseHasMoved` 标记确保鼠标至少移动一次才能按键触发

## 规则系统

**SiteRule**: `id` + `matches(host)` + `probe?` + `resolve(ctx)` → `ZoomResult`

**ResolveContext**: `{url, element, pageUrl, fetchWithProxy, getCookie}`

**ZoomResult**: `{type, sources[], audioUrl?, headers?, caption?}`

## 跨域代理

Content → `HALO_HZ_PROXY_AJAX` → Background fetch → Response

## B 站规则

| 场景     | URL 模式               | 数据源                                |
| -------- | ---------------------- | ------------------------------------- |
| 视频     | `/video/BVxxx`         | `__playinfo__` 或 `/x/player/playurl` |
| 番剧     | `/bangumi/play/epXXX`  | `/pgc/player/web/playurl`             |
| 国际剧集 | `bilibili.tv/play/N/M` | `/intl/gateway/web/playurl?ep_id=`    |
| 国际视频 | `bilibili.tv/video/N`  | `/intl/gateway/web/playurl?aid=`      |

DASH: video+audio 分离 → 按 `bandwidth` 降序排序取最高

## 布局算法 (viewer.ts#updateLayout)

```text
四个方向 = 源边延长到屏幕两端 → 对角属于相邻两区域
          Right/Left: 高度=整个视口
          Top/Bottom: 宽度=整个视口
```

1. 遍历四方向，计算各方向最大可显示尺寸
2. **边对齐**: 浮图平行边覆盖源对应边
3. 选面积最大方向
4. Fallback: 居中缩放
