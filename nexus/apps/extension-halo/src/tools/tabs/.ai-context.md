# Tabs Module Context

## 身份

名称: Tabs Manager | 角色: 垂直标签页管理 | 状态: Ready

## 功能

- **垂直列表**: 解决标签页过多拥挤问题
- **搜索**: 标题与 URL 实时过滤
- **筛选**: 快速查找有声/置顶标签
- **操作**: 切换/关闭/静音状态展示

## 架构

- **Core**: `chrome.tabs` (Permissions: tabs)
- **State**: `list/active/audible/muted`
- **Events**: `onCreated/onUpdated/onRemoved/onActivated`

## 规则

- 乐观更新 (Optimistic UI)
- 懒加载 Favicon (默认 chrome API)
