# Base64 模块上下文

## 职责

Base64 编解码 | 文件转 Base64 | URL 安全模式

## 文件结构

| 文件        | 职责                    | 行数 |
| ----------- | ----------------------- | ---- |
| `types.ts`  | 类型定义                | 10   |
| `core.ts`   | 编解码逻辑 (UTF-8 支持) | 50   |
| `panel.tsx` | UI                      | ~120 |
| `index.ts`  | 导出入口                | 5    |

## 功能

- 文本 ↔ Base64 (支持 UTF-8 中文)
- URL Safe 模式 (+/ -> -\_)
- 文件拖拽转 Base64 DataURL
- 结果一键复制/交换

## 依赖

无外部依赖 | 纯原生 TextEncoder/atob API

## 体积

~3KB
