# Regex 模块上下文

## 职责

正则表达式测试器 | 实时匹配 | 替换预览

## 文件结构

| 文件        | 职责           | 行数 |
| ----------- | -------------- | ---- |
| `types.ts`  | 类型+预设      | 43   |
| `core.ts`   | 执行/验证/替换 | 90   |
| `panel.tsx` | UI             | ~180 |
| `index.ts`  | 导出入口       | 5    |

## 功能

- 实时正则匹配高亮
- Flags: g/i/m/s/u 切换
- 预设模板 (Email/URL/IP/Phone/Date/HexColor)
- 替换预览
- 匹配结果列表 (line/column/groups)

## 依赖

无外部依赖 | 纯 JavaScript RegExp API

## 体积

~8KB (gzip 后 ~3KB)
