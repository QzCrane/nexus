# Timestamp 模块上下文

## 职责

时间戳转换 | 格式化

## 文件结构

| 文件        | 职责            | 行数 |
| ----------- | --------------- | ---- |
| `types.ts`  | 类型            | 10   |
| `core.ts`   | 核心逻辑 (Intl) | 40   |
| `panel.tsx` | UI              | ~90  |
| `index.ts`  | 导出            | 5    |

## 功能

- 当前时间显示 (秒/毫秒)
- 互转: Timestamp <-> Date String
- 支持 ISO/Local 格式显示

## 依赖

无外部依赖 | `Intl.DateTimeFormat`
