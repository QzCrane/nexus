# HALO 调研汇总 (2025)

> 目标: 识别痛点 → 差异化竞争 | 核心: Zero upload. Zero tracking. Zero cost.

## 📊 竞品痛点 (头部扩展)

- Dark Reader (6M+): 性能差 (500ms+), CPU 高. → **HALO: <50ms CSS 注入**
- OneTab (2M+): 易丢数据, 无同步. → **HALO: 双重备份 + 免费同步**
- Lightshot (10M+): 隐私泄露 (公开上传). → **HALO: 100% 本地 + 本地 OCR**
- Toby (1M+): 昂贵订阅 ($40/年). → **HALO: 开源永久免费**
- SmoothScroll / Clipboard: 隐私/性能问题. → **HALO: 高手感 + 零隐私风险**

## 🔥 需求频率

1. 性能拖慢 (愤怒) | 2. 数据丢失 (绝望) | 3. 隐私泄露 (恐惧) | 4. 复杂难用 (困惑)

## 💡 HALO 护城河

L3 信任: 开源 + 零遥测 | L2 性能: CSS 注入 < 50ms | L1 隐私: 100% 本地 | L0 功能: 深色+标签+截图 一站式

## 📅 趋势机会 (纳入 P2)

- ✅ 阅读模式: 去广告纯净体验 (对标简陋的默认 Reader).
- ✅ 快捷便签: 页面级笔记，与截图联动.
- ❌ 页面录制/下载管理: 复杂度高且非核心.
