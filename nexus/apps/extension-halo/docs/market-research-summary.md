# HALO 调研汇总 (2025)

> 目标: 识别痛点 → 差异化竞争 | 核心: Zero upload. Zero tracking. Zero cost.

## 📊 竞品痛点 (头部扩展)

| 竞品         | 用户量 | 痛点                    | HALO 差异化          |
| ------------ | ------ | ----------------------- | -------------------- |
| Dark Reader  | 6M+    | 性能差 (500ms+), CPU 高 | <50ms CSS 注入       |
| OneTab       | 2M+    | 易丢数据, 无同步        | 双重备份 + 免费同步  |
| Lightshot    | 10M+   | 隐私泄露 (公开上传)     | 100% 本地 + 本地 OCR |
| Toby         | 1M+    | 昂贵订阅 ($40/年)       | 开源永久免费         |
| SmoothScroll | 500k+  | 隐私/性能问题           | 高手感 + 零隐私风险  |

## 🔥 需求频率

1. 性能拖慢 (愤怒) | 2. 数据丢失 (绝望) | 3. 隐私泄露 (恐惧) | 4. 复杂难用 (困惑)

## 💡 HALO 护城河

| 层级    | 优势                  |
| ------- | --------------------- |
| L3 信任 | 开源 + 零遥测         |
| L2 性能 | CSS 注入 < 50ms       |
| L1 隐私 | 100% 本地             |
| L0 功能 | 深色+标签+截图 一站式 |

## 📅 趋势机会 (已纳入)

- ✅ 阅读模式: 去广告纯净体验
- ✅ 快捷便签: 页面级笔记
- ❌ 页面录制/下载管理: 复杂度高且非核心
