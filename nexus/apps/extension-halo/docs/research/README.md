# HALO research

This directory contains dated evidence and candidate product gaps. It does not define implemented capability or architecture.

- [`market-landscape-2025.md`](market-landscape-2025.md): durable problem hypotheses derived from 2025 research; dynamic competitor facts require revalidation.
- [`feature-gap-analysis.md`](feature-gap-analysis.md): candidate workflow backlog and promotion gates.
- [`../../../../docs/research/README.md`](../../../../docs/research/README.md): repository-level research standard.

A research conclusion becomes architecture only after it is converted into a testable constraint and accepted in [`../architecture.md`](../architecture.md). It becomes delivered behavior only after source, tests, production artifacts, and public projections agree.
