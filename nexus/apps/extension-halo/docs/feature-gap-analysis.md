# Halo 工具功能完整性分析 (竞品对标)

## 目标: 秒杀全网所有竞品

---

## 1. JSON Formatter - 当前状态 vs 竞品

### ✅ 已有功能

- [x] 格式化/美化
- [x] 压缩/Minify
- [x] 语法验证
- [x] 缩进选项 (2/4 spaces)
- [x] 键排序
- [x] 字符/行数统计

### ❌ 缺失的竞品功能 (需添加)

- [ ] **Tree View** - 树状可折叠视图 (JSON Hero, JSONLint)
- [ ] **JSONPath 查询** - 支持 $.store.book[*].author 查询
- [ ] **JSON → CSV/YAML/XML 转换** - 一键转换
- [ ] **URL/文件导入** - 从 URL 或拖拽文件加载
- [ ] **Diff 对比** - 两个 JSON 对比
- [ ] **错误定位** - 错误行号高亮

---

## 2. Hash Generator - 当前状态 vs 竞品

### ✅ 已有功能

- [x] MD5, SHA-1, SHA-256, SHA-512
- [x] 文本哈希
- [x] 文件哈希
- [x] 大小写切换
- [x] 同时显示所有算法

### ❌ 缺失的竞品功能 (需添加)

- [ ] **HMAC 支持** - 带密钥的哈希
- [ ] **SHA-3 系列** - SHA3-256, SHA3-512
- [ ] **哈希验证** - 输入已知哈希值进行比对
- [ ] **CRC32** - 常用校验和
- [ ] **批量文件哈希** - 多文件同时计算

## 优先级排序

### P0 - 必须有 (核心工具增强)

1. JSON Tree View + JSONPath
2. Hash HMAC + 验证功能
3. QR Code 颜色 + Logo
4. Color Picker WCAG 对比度

### P1 - 应该有 (差异化优势)

1. Base64 图片预览
2. Password Generator 强度指示
3. Regex 正则解释
4. Timestamp 时区列表

### P2 - 可以有 (加分项)

1. JSON Diff
2. UUID v5 命名空间
3. 批量处理功能
