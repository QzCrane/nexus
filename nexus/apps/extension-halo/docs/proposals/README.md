# HALO proposals

Proposals define candidate boundaries and acceptance criteria. They do not prove implementation or release status.

- [`hover-zoom-v2.md`](hover-zoom-v2.md): hover-preview architecture and closure gates.
- [`bilibili-danmaku.md`](bilibili-danmaku.md): optional timed-comment overlay for supported Bilibili previews.

A proposal is promoted only after its owner, contracts, permissions, lifecycle, implementation, tests, production performance, accessibility, documentation, and release projections close together. Historical estimates and completion marks remain evidence, not authority.
