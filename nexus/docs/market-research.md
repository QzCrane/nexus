## 1. Dark Reader

**核心数据**: 6M+ 用户 (Chrome) | 4.7/5 (12.8k 评价) | **1360** 开放 Issues | 372 Bug 标签

### 🔴 核心痛点 (按频次排序)

**P0 性能问题 ⭐⭐⭐⭐⭐**

| 子问题            | 描述                       | 来源             |
| ----------------- | -------------------------- | ---------------- |
| **浏览器变慢 2x** | Benchmark 测试显示性能减半 | Reddit           |
| **高 CPU 占用**   | 关闭状态仍消耗 CPU         | Reddit/Store     |
| **输入卡顿**      | 地址栏输入延迟             | GitHub #14877    |
| **Reddit 崩溃**   | Firefox 警告"扩展拖慢页面" | Reddit (2024 Q4) |
| **白色闪烁**      | 页面加载时先白后黑         | 普遍反馈         |

**技术根因**: DOM 遍历 + JS 注入在页面渲染后执行

**P1 网站兼容性问题 ⭐⭐⭐⭐**

| 子问题              | 描述                          |
| ------------------- | ----------------------------- |
| Akamai CDN          | 触发 IP 封禁 (误判为机器人)   |
| PDF 查看            | 工具栏/背景被反转             |
| adopted stylesheets | Firefox 无法直接访问 → 需绕路 |
| 图标变黑            | 无法识别 SVG/icon 颜色        |

**P2 复杂配置 ⭐⭐⭐**

- **模式过多**: Filter/Filter+/Static/Dynamic 让用户困惑
- **站点设置散落**: 需逐站调整参数
- **恢复困难**: 卸载后浏览器颜色仍异常 (chrome://flags 被改)

**P3 安全顾虑 ⭐⭐**

- 恶意克隆版本频现 (窃取数据)
- 用户难辨真伪

### 🟢 竞品分析

| 扩展                | 优势                     | 劣势            |
| ------------------- | ------------------------ | --------------- |
| **UltimaDark** (FF) | 预渲染拦截 → 无白闪/极快 | 仅 Firefox      |
| **Midnight Lizard** | 低资源/精细调节          | 配置更复杂      |
| **Night Eye**       | 智能转换/无反色          | 付费            |
| **浏览器原生**      | 零扩展 `force-dark` flag | 效果差/无白名单 |

### 💡 HALO 差异化方向

| 痛点     | HALO 方案                         |
| -------- | --------------------------------- |
| 性能慢   | **CSS filter 注入** (非 DOM 遍历) |
| 白色闪烁 | **早期注入** via `document_start` |
| 复杂配置 | **一键开关 + 智能白名单**         |
| 高 CPU   | **纯 CSS 无 JS 轮询**             |
| 安全     | **开源 + 零遥测**                 |

**性能目标**: Dark Reader 500-2000ms → HALO <50ms (10x 提升)

**MVP 功能 (v0.1 W1-2)**: 全局开关 | CSS filter invert(1) hue-rotate(180deg) | 站点白名单 | 图片/视频保护 | 性能 <50ms / <5MB 内存

### 📝 用户原声

> "Dark Reader makes Chrome lag when typing in address bar" — GitHub
> "Nearly 2x slower in browser benchmark with Dark Reader on" — Reddit
> "Firefox shows warning that Dark Reader slows down Reddit" — Reddit 2024
> "Access Denied on Akamai sites - 10 min IP ban triggered" — GitHub #8774

## 2. OneTab/Toby

| 扩展   | 用户量 | 评分  | 痛点密度    |
| ------ | ------ | ----- | ----------- |
| OneTab | 2M+    | 4.3/5 | 高          |
| Toby   | 1M+    | 4.6/5 | 中 (付费墙) |

### 🔴 OneTab 核心痛点

**P0 数据丢失 ⭐⭐⭐⭐⭐**

| 问题             | 描述                           |
| ---------------- | ------------------------------ |
| **标签全部丢失** | Chrome 崩溃/更新后数千标签消失 |
| **无云备份**     | 仅本地存储，无自动同步         |
| **恢复困难**     | 需手动导出 TXT，用户常忘记     |
| **存储溢出**     | localStorage 满后静默丢弃      |

> 用户原声: "Lost thousands of tabs and years of collected data"

**P1 无跨设备同步 ⭐⭐⭐⭐**

- 手机 ↔ 电脑无法共享标签
- 多设备场景无解
- 用户被迫手动导出/导入

**P2 性能问题 ⭐⭐⭐**

- 恢复大量标签时卡顿
- 页面列表过长时 UI 变慢
- 开发者承认 "restoring thousands of tabs simultaneously can lead to performance issues"

**P3 功能单一 ⭐⭐**

- 无分组/文件夹
- 无搜索功能
- 无标签预览

### 🔴 Toby 核心痛点

**P0 付费墙 ⭐⭐⭐⭐⭐**

| 问题           | 描述                                        |
| -------------- | ------------------------------------------- |
| **$40/年订阅** | 2024 年从免费转付费                         |
| **用户愤怒**   | "exploitative pricing" "reneged on promise" |
| **功能锁定**   | 免费版功能受限                              |

**P1 信任危机 ⭐⭐⭐**

- 曾承诺永久免费
- 用户大量流失至替代品

### 🟢 竞品分析

| 扩展                 | 优势                   | 劣势          |
| -------------------- | ---------------------- | ------------- |
| **Workona**          | 工作区/云同步/自动挂起 | 复杂/付费     |
| **Session Buddy**    | 会话管理/崩溃恢复      | 无云同步      |
| **Tab Manager Plus** | 可视化/去重            | 功能有限      |
| **Tabwise**          | AI 自动分类            | 新产品/未验证 |
| **Side Space**       | 垂直标签/AI 分组       | 仅 2025 新品  |

### 💡 HALO 差异化方向

| 痛点     | HALO 方案                                           |
| -------- | --------------------------------------------------- |
| 数据丢失 | **本地 + 云双备份** (IndexedDB + 可选 Google Drive) |
| 无同步   | **跨设备同步** via chrome.storage.sync              |
| 付费墙   | **永久免费 + 开源**                                 |
| 功能单一 | **AI 模糊搜索** + 分组 + 预览                       |

**MVP 功能 (v0.2 W5-6)**: 一键保存 | 分组/文件夹 | 模糊搜索 (Fuse.js) | 自动备份 | 跨设备同步 | 恢复确认

**技术选型**: IndexedDB + chrome.storage.sync + Fuse.js

## 3. Lightshot

**核心数据**: 10M+ 用户 (全平台) | 扩展 + 桌面应用 | **严重隐私风险**

### 🔴 核心痛点 (按严重程度)

**P0 隐私安全灾难 ⭐⭐⭐⭐⭐**

| 问题             | 描述                           |
| ---------------- | ------------------------------ |
| **公开 URL**     | 上传截图获得可猜测的公开链接   |
| **URL 可遍历**   | 简单修改 URL 即可查看他人截图  |
| **无加密**       | 服务器存储无任何保护           |
| **敏感信息泄露** | 银行详情/通讯录/私密视频被曝光 |
| **机构封禁**     | Missouri S&T 等高校已禁用      |

> ⚠️ 2020 年事件: Lightshot 数据泄露导致钓鱼攻击 + 加密货币账户被盗

**P1 默认上传服务器 ⭐⭐⭐⭐**

- 用户不知情下截图被上传
- 无明确的"仅本地保存"选项
- 即使删除本地，服务器仍保留

**P2 功能有限 ⭐⭐**

- 批注工具简陋
- 无滚动截图
- 无 OCR
- 无延迟截图

### 🟢 竞品分析

| 工具              | 类型       | 本地保存    | 隐私      | 功能                    |
| ----------------- | ---------- | ----------- | --------- | ----------------------- |
| **ShareX**        | 桌面 (Win) | ✅ 完全控制 | ✅ 开源   | 最强: 滚动/录屏/OCR/GIF |
| **Greenshot**     | 桌面 (Win) | ✅ 自动保存 | ✅ 开源   | 良好: 批注/插件         |
| **Snipping Tool** | Win 内置   | ✅ 自动     | ✅ 本地   | 基础: 区域/延迟/录屏    |
| **FireShot**      | 扩展       | ✅ 本地     | ✅ 无上传 | 良好: 整页/PDF          |
| **GoFullPage**    | 扩展       | ✅ 本地     | ✅ 无权限 | 简洁: 整页截图          |

### 💡 HALO 差异化方向

| 痛点     | HALO 方案                                |
| -------- | ---------------------------------------- |
| 隐私泄露 | **100% 本地处理** 无任何上传             |
| 无加密   | **无需加密** (不存服务器)                |
| 功能简陋 | **丰富批注**: 箭头/方框/文字/马赛克/高亮 |
| 无 OCR   | **本地 OCR** (Tesseract.js)              |

**MVP 功能 (v0.2 W6)**: 区域/窗口/整页截图 | 批注工具 | 本地保存 (PNG/JPEG) | 复制到剪贴板 | 快捷键 | 隐私声明"永不上传"

**进阶功能 (Q2)**: 滚动截图 | 延迟截图 | 本地 OCR (Tesseract.js) | 历史记录 (本地) | 快速分享 (本地 HTML)

**技术选型**: chrome.tabs.captureVisibleTab + html2canvas (整页) | Canvas/Fabric.js 批注 | Tesseract.js (WASM) OCR | IndexedDB 历史

### 📝 用户原声

> "Lightshot uploads are publicly accessible, anyone can view them by guessing URLs" — Security Report
> "Missouri S&T blocked Lightshot on all managed computers due to cybersecurity vulnerabilities" — mst.edu 2025
> "I found someone's bank details browsing random Lightshot URLs" — Reddit
> "ShareX is overkill, I just want quick local screenshots" — Reddit

### 🔗 安全事件时间线

| 时间    | 事件                        |
| ------- | --------------------------- |
| 2020    | 数据泄露导致钓鱼攻击        |
| 2020    | 加密货币账户信息被发现      |
| 2024    | 持续有敏感信息曝光报告      |
| 2025.08 | Missouri S&T 禁用 Lightshot |

**机会**: 用户正在寻找隐私友好的替代品，HALO 的"零上传"承诺可作为核心卖点

## 4. 二维码

### 1.1 QR 竞品概况

| 扩展              | 用户量 | 核心问题 |
| ----------------- | ------ | -------- |
| QR Code Generator | 5M+    | 隐私风险 |
| Scan QR           | 1M+    | 功能单一 |

### 1.2 QR 核心痛点

| 问题              | 严重性     | 描述                           |
| ----------------- | ---------- | ------------------------------ |
| **隐私泄露**      | ⭐⭐⭐⭐⭐ | 动态 QR 追踪位置/设备/浏览习惯 |
| **Quishing 钓鱼** | ⭐⭐⭐⭐⭐ | 恶意 QR 绕过邮件安全扫描       |
| **过度权限**      | ⭐⭐⭐⭐   | 要求访问所有网站/剪贴板        |
| **供应链攻击**    | ⭐⭐⭐⭐   | 2024 大规模扩展劫持事件        |
| **功能有限**      | ⭐⭐⭐     | Chrome 内置无品牌定制/追踪     |

### 1.3 QR 差异化策略

| 痛点 | 方案                        |
| ---- | --------------------------- |
| 隐私 | **离线生成** 无网络请求     |
| 钓鱼 | **URL 预览** 扫描前显示目标 |
| 权限 | **最小权限** 仅 activeTab   |
| 功能 | 生成+扫描+历史记录          |

### 1.4 QR MVP 功能 (W4)

```text
├─ 当前页面 → QR 生成 (一键)
├─ 自定义内容 → QR 生成
├─ 摄像头/图片 → QR 扫描
├─ URL 安全预览 (防钓鱼)
├─ 本地历史记录
└─ 离线工作
```
