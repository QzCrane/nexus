# 文档质量与无损压缩约束

**核心目标**: 消除冗余，将自然语言转化为“结构化知识逻辑”，最高效利用 Token。

## 压缩方法论

1. **符号化与矩阵化**:
   - 严禁散文式描述，必须使用**决策矩阵（表格）**描述逻辑判断。
   - 使用 `→` 表示流程，`|` 表示或。
2. **知识去重**:
   - 规则仅在最相关的核心上下文定义一次。
   - 其他地方通过“单线关联”引用，不进行重复描述。
3. **消除修饰语**:
   - 剔除引导词（如“请注意”、“我们建议”）、背景陈述、礼貌用词。
   - 仅保留：**技术事实、约束边界、接口签名**。
4. **术语提炼**:
   - 使用经过定义的精准术语（如：Sticky 锁存, PENDING 待定）。

## 维护红线

- **.ai-context.md**: 必须维持在 30 行以内。
- **验证**: 每次修改后必须自检是否能用更少字数保持相同信息熵。
