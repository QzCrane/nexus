# 文档压缩规范

**目标**: 最高信息熵/Token 比。

## 格式选择

- 2 列映射 → `A: B` 或 `A → B`
- 流程链 → `A → B → C`
- ≥3 列对比 → 表格
- 约束列表 → `- ` 列表

## 压缩词汇

禁用 → 替代:

- 请注意/注意 → 直接陈述
- 我们建议/建议 → 直接陈述
- 的时候/当...时 → 删除或 `→`
- 进行/执行/实现 → 直接动词
- 相关的/相应的 → 删除
- 可以/能够/应该 → 删除

## 内容规则

- 单点定义: 规则仅在最相关位置定义一次
- 引用替代: 其他位置用 `→ 见 [文档名]`
- 分隔符一致: 全局统一用 `:` 或 `→`

## 硬限位

- .ai-context.md: ≤30 行
- 单行: ≤80 字符
