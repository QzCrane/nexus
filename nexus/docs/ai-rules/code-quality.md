# 代码质量约束

## 文件大小

| 类型            | 上限   | 超限处理   |
| --------------- | ------ | ---------- |
| 源码文件        | 200 行 | 必须拆分   |
| 入口 `index.ts` | 50 行  | 只做导出   |
| 类型文件        | 150 行 | 按领域拆分 |

## 触发拆分的信号

- 单个函数超过 50 行
- 文件包含 3+ 不相关职责
- import 超过 15 行
- 需要添加"区块注释"分隔

## 拆分模板

```
module/
├── index.ts         # 公共导出
├── types.ts         # 类型定义
├── core.ts          # 核心逻辑
└── [feature].ts     # 具体功能
```

## 修改现有代码前

```
□ 目标文件 > 150 行？ → 考虑拆分
□ 目标文件 > 200 行？ → 禁止添加，必须先拆分
□ 新增 > 50 行？ → 创建新文件
□ 新增不同职责？ → 创建新文件
```

## 目录结构

每个模块目录**必须**包含：

- `index.ts` - 公共 API
- `.ai-context.md` - AI 上下文（推荐）

## ❌ 禁止

- 在 `src/` 放编译产物 (`.js/.d.ts`)
- 超过 3 层嵌套目录
- 在 `index.ts` 放业务逻辑
