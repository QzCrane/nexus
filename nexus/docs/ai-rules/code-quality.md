# 代码质量约束

**硬限位**: 源码由 ≤200 行文件组成， index.ts 仅限导出（≤50 行）。

## 拆分触发点

- 函数 > 50 行 或 文件 > 150 行（即刻预警）。
- 职责 > 2 个 或 Import 逻辑混乱。

## 模块标准结构

```text
module/
├── index.ts        # 唯一对外出口
├── types.ts        # 领域类型定义
├── core.ts         # 稳定核心算法
└── [feature].ts    # 具体原子功能
```

## 修改红线

- **禁止**: 在超过 200 行的文件中新增代码（必须先重构拆分）。
- **原则**: 单一文件单一职责，三层目录深度上限。
