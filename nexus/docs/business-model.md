# NEXUS 商业模式 (2025)

> 核心: 零上传 / 免费开源 / Freemium 变现
> 定位: 隐私优先的生产力套件 (Spectra, Halo, Cortex)

## 📊 市场对标

Dark Reader(转订阅) / Bitwarden(Freemium) / CSS Scan(一次性购买) / uBlock Origin(零盈利)

## 💰 盈利模型

1. **Freemium** (⭐⭐⭐): 基础版全开 / Pro 版: 主题定制, 无限资源, AI 高级功能, 优先支持.
2. **订阅制**: $9.99/年 (个人) / $19.99/年 (家庭) / $4.99/月 (企业).
3. **一次性购买**: $29.99 (永久 Pro) / $59.99 (全家桶).
4. **企业版** (⭐⭐⭐⭐): 自托管 / SSO 集成 / SLA 保障.

🚫 **淘汰模式**: 广告 / 数据出售 / 强制付费 (违背隐私原则).

## 🚀 增长路径

Q1-Q2 (10k DAU): 100% 免费开源 → 用户增长
Q3 (50k DAU): 推出 Pro 版 → 预期转化 1% ($5k/年)
2026 (500k DAU): 企业版 + API 授权 → 预期 $50k-100k/年

## 💎 Pro 功能

Spectra: 人声分离 (Local AI), 1080p 导出, 跨设备同步, 无限书签.
Halo: 自定义主题, 无限标签组, AI 模糊搜索, 云备份 (GDrive), OCR.
Cortex: GPT-4 模型支持, 批量摘要, 自定义工作流.
