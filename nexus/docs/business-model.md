## 💰 可行盈利模式

### 1. Freemium (推荐 ⭐⭐⭐⭐⭐)

```
免费版: 核心功能 (深色/标签/截图基础版)
Pro版: 高级功能 ($9.99/年 或 $29.99 永久)
```

**Pro 功能示例**:
| 功能 | 免费 | Pro |
|------|------|-----|
| 深色模式 | ✅ 基础 | ✅ 主题定制 |
| 标签分组 | ✅ 5 组 | ✅ 无限 |
| AI 搜索 | ❌ | ✅ |
| 截图批注 | ✅ 基础 | ✅ 全套 |
| 云同步 | ❌ | ✅ Google Drive |
| 优先支持 | ❌ | ✅ |

### 2. 订阅制 (推荐 ⭐⭐⭐⭐)

```
个人: $9.99/年 (≈¥72)
家庭: $19.99/年 (5设备)
企业: $4.99/用户/月
```

**参考**: Dark Reader 2024 年转型同价位

### 3. 一次性购买 (推荐 ⭐⭐⭐)

```
终身 Pro: $29.99-49.99
捆绑包: SPECTRA + HALO + CORTEX = $59.99
```

**优势**: 用户偏好，无持续付款压力

### 4. 打赏/赞助 (补充 ⭐⭐)

```
GitHub Sponsors
Buy Me a Coffee
Patreon
```

**现实**: 仅靠捐赠难以维持，Dark Reader 曾抱怨收入低于平均工程师薪资

### 5. 企业版 (长期 ⭐⭐⭐⭐)

```
自托管部署
批量授权
SSO/SAML 集成
优先支持 SLA
```

**参考**: Bitwarden 75%+ 收入来自企业客户

## 🚫 不推荐的模式

| 模式         | 原因                     |
| ------------ | ------------------------ |
| **广告**     | 与"零追踪"承诺冲突       |
| **数据出售** | 违背隐私原则             |
| **强制付费** | 丢失用户信任 (Toby 教训) |
| **功能锁死** | 免费版过于残废 → 差评    |
