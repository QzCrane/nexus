# 策略重构计划 V2 (已完成)

**目标**: 简化模式决策、优化 UI 留存、完善站点库。

## 1. 策略引擎 (P0)

- **核心**: `无高级需求 → LITE`；`有需求 + 安全 → WEB`；`有需求 + 受限 → CAPTURE`。
- **高级处理 (Advanced)**: 音量>100 | EQ | 压缩器 | 低音增强 | 频谱。

## 2. 状态管理 (P1)

- **TabAudioState**: 记录 `hasMedia`, `lastAudible`, `lastActivated`。
- **显示策略**: 活跃页显示；非活跃页 60s 暂停缓冲期，超时移除卡片。

## 3. 站点规则 (P2)

- **统一结构**: 合并播放/预览路径解析。
- **覆盖**: 涵盖 抖音、B 站、YTB、Spotify、Netflix 等 12+ 主流平台。

## 4. 模式判定表

| 需求 | 受限 | 模式     | 颜色 |
| ---- | ---- | -------- | ---- |
| ❌   | 任意 | LITE     | 🔵   |
| ✅   | ❌   | WEBAUDIO | 🔵   |
| ✅   | ✅   | CAPTURE  | 🟣   |
