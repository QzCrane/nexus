# HALO 补充功能调研 (2024-2025)

> **目标**: 调研 HALO 剩余 4 个功能的竞品痛点  
> **调研日期**: 2025-12-28

---

## 1️⃣ 二维码生成/扫描

### 1.1 QR 竞品概况

| 扩展              | 用户量 | 核心问题 |
| ----------------- | ------ | -------- |
| QR Code Generator | 5M+    | 隐私风险 |
| Scan QR           | 1M+    | 功能单一 |
| Chrome 内置       | -      | 功能有限 |

### 1.2 QR 核心痛点

| 问题              | 严重性     | 描述                           |
| ----------------- | ---------- | ------------------------------ |
| **隐私泄露**      | ⭐⭐⭐⭐⭐ | 动态 QR 追踪位置/设备/浏览习惯 |
| **Quishing 钓鱼** | ⭐⭐⭐⭐⭐ | 恶意 QR 绕过邮件安全扫描       |
| **过度权限**      | ⭐⭐⭐⭐   | 要求访问所有网站/剪贴板        |
| **供应链攻击**    | ⭐⭐⭐⭐   | 2024 大规模扩展劫持事件        |
| **功能有限**      | ⭐⭐⭐     | Chrome 内置无品牌定制/追踪     |

### 1.3 QR 差异化策略

| 痛点 | 方案                        |
| ---- | --------------------------- |
| 隐私 | **离线生成** 无网络请求     |
| 钓鱼 | **URL 预览** 扫描前显示目标 |
| 权限 | **最小权限** 仅 activeTab   |
| 功能 | 生成+扫描+历史记录          |

### 1.4 QR MVP 功能 (W4)

```text
├─ 当前页面 → QR 生成 (一键)
├─ 自定义内容 → QR 生成
├─ 摄像头/图片 → QR 扫描
├─ URL 安全预览 (防钓鱼)
├─ 本地历史记录
└─ 离线工作
```

## 2️⃣ 丝滑滚动

### 2.1 滚动竞品概况

| 扩展                           | 用户量 | 核心问题     |
| ------------------------------ | ------ | ------------ |
| SmoothScroll                   | 500k+  | YouTube 卡顿 |
| Chromium Wheel Smooth Scroller | 200k+  | 性能问题     |
| Chrome 内置 (flags)            | -      | 老机器卡     |

### 2.2 滚动核心痛点

| 问题             | 严重性   | 描述              |
| ---------------- | -------- | ----------------- |
| **YouTube 卡顿** | ⭐⭐⭐⭐ | 特定网站性能骤降  |
| **老设备卡顿**   | ⭐⭐⭐   | GPU 资源消耗高    |
| **扩展消失**     | ⭐⭐⭐   | Logitech 扩展下架 |
| **配置复杂**     | ⭐⭐     | 参数过多          |

### 2.3 滚动差异化策略

| 痛点   | 方案                                 |
| ------ | ------------------------------------ |
| 性能   | **CSS scroll-behavior** 优先 (零 JS) |
| 兼容   | 站点白名单 (自动禁用问题站)          |
| 配置   | 简单滑块: 速度+惯性                  |
| 老设备 | 自动降级模式                         |

### 2.4 滚动 MVP 功能 (W4)

```text
├─ 一键开关
├─ 速度/惯性滑块 (2个参数)
├─ 站点白名单
├─ 键盘方向键平滑
└─ 自动检测低性能设备
```

## 3️⃣ 剪贴板历史

### 3.1 剪贴板竞品概况

| 扩展                  | 用户量 | 核心问题 |
| --------------------- | ------ | -------- |
| Clipboard History Pro | 500k+  | 隐私风险 |
| Copy History +        | 100k+  | 功能有限 |
| Windows 内置 (Win+V)  | -      | 仅 5 条  |

### 3.2 剪贴板核心痛点

| 问题           | 严重性     | 描述                       |
| -------------- | ---------- | -------------------------- |
| **隐私泄露**   | ⭐⭐⭐⭐⭐ | 闭源扩展可访问所有复制内容 |
| **明文存储**   | ⭐⭐⭐⭐   | 密码/敏感信息无加密        |
| **劫持风险**   | ⭐⭐⭐⭐   | 恶意扩展替换剪贴板内容     |
| **浏览器历史** | ⭐⭐⭐     | 更新后要求访问浏览历史     |
| **广告过多**   | ⭐⭐⭐     | 头部扩展因广告被下架       |

### 3.3 剪贴板差异化策略

| 痛点 | 方案                      |
| ---- | ------------------------- |
| 隐私 | **开源** 可审计           |
| 明文 | 敏感内容检测 + 可选加密   |
| 劫持 | 只读模式 (不修改剪贴板)   |
| 权限 | 仅 clipboardRead (无网络) |

### 3.4 剪贴板 MVP 功能 (W8)

```text
├─ 无限历史记录 (本地)
├─ 搜索/筛选
├─ 收藏/置顶
├─ 快捷键粘贴
├─ 站点控制 (启用/禁用)
└─ 敏感内容检测警告
```

## 4️⃣ 网站时间限制

### 4.1 限时竞品概况

| 扩展          | 用户量 | 核心问题 |
| ------------- | ------ | -------- |
| StayFocusd    | 1M+    | 易绕过   |
| BlockSite     | 10M+   | 付费墙   |
| LeechBlock NG | 500k+  | 配置复杂 |

### 4.2 限时核心痛点

| 问题           | 严重性     | 描述                   |
| -------------- | ---------- | ---------------------- |
| **易绕过**     | ⭐⭐⭐⭐⭐ | 换浏览器/改时间/清数据 |
| **配置复杂**   | ⭐⭐⭐⭐   | StayFocusd 界面混乱    |
| **付费墙**     | ⭐⭐⭐⭐   | BlockSite 核心功能收费 |
| **移动端问题** | ⭐⭐⭐     | Android 辅助功能被关闭 |
| **浏览器兼容** | ⭐⭐       | Brave 不工作           |

### 4.3 常见绕过方式汇总

```text
1. 换浏览器 (StayFocusd 仅 Chrome)
2. 隐私模式
3. 修改系统时间
4. 清除扩展数据
5. 禁用扩展
6. 手机端清后台
```

### 4.4 限时差异化策略

| 痛点 | 方案                  |
| ---- | --------------------- |
| 绕过 | **多重防护** (详见下) |
| 配置 | 简单界面: 网站+时间   |
| 付费 | 免费基础版            |

### 4.5 防绕过策略

```text
├─ 跨浏览器同步 (chrome.storage.sync)
├─ 时间服务器校验 (防改时间)
├─ 挑战任务 (修改设置需完成)
├─ 锁定模式 (指定时段无法禁用)
└─ 统计报告 (羞耻激励)
```

### 4.6 限时 MVP 功能 (Q2)

```text
├─ 每日限时 (站点级别)
├─ 时段屏蔽 (如工作时间)
├─ 简单白名单
├─ 剩余时间提醒
├─ 强制午休模式
└─ 每周统计报告
```

## 🎯 HALO 统一定位

```
"轻量工具集，隐私优先"

核心原则:
1. 零网络请求 (能离线就离线)
2. 最小权限 (能不要就不要)
3. 开源透明 (代码可审计)
4. 简单易用 (一键操作)
```
