# Scripts

**用途**: 构建/资源处理/架构验证脚本。

## 脚本清单

| 脚本                   | 用途           | 触发     |
| ---------------------- | -------------- | -------- |
| verify-architecture.js | 架构完整性检查 | prebuild |
| generate-icons.js      | 图标多尺寸生成 | 手动     |
| remove-white-bg.js     | 白背景转透明   | 手动     |

## verify-architecture

- 检查 .ai-context.md 存在性
- 检查 contracts 纯净性
- 检查源码行数上限 (150/200)
- 检查硬编码 Action
- 检查 HTML 资源引用
