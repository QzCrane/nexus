# Audio Engine

**用途**：WebAudio 音频图管理 + 网站策略判断

## 公共 API

```typescript
import { PolicyEngine, WebAudioController } from '@nexus/audio-engine';
```

契约：`@nexus/contracts/audio.contracts.ts`

## 音频处理链

```
Media → GainNode → BiquadFilter x10 → Compressor → AnalyserNode → Destination
```

## 约束

- AudioContext：每个标签页一个，需 resume()
- CORS：跨域需回退 Tab Capture
- 释放：标签页关闭时调用 dispose()
