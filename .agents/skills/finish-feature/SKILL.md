# Finish feature

- Reconstruct the requested behavior from the final diff, [`rules.md`](../../../rules.md), domain owner, and live release scripts.
- Confirm contract, implementation, failure handling, lifecycle, tests, documentation, privacy, and production projections close the same behavior.
- Run only the current focused and applicable repository gates, then review scope and dirty work.
- Commit, push, merge, publish, or clean up only when explicitly authorized.
